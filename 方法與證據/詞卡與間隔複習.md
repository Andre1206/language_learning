# 詞卡與間隔複習

最後更新：2026-11-08

本文件是 [練習方法與證據框架](../練習方法與證據框架.md) 第 10.3 節的個別方法文件，詳細說明「主動提取詞卡＋答後核對＋間隔複習」如何實作、有哪些主要變體，以及目前證據支持到哪裡。目標讀者是想依自己的能力需求製作或選用詞卡、並判斷這種方法是否適合的台灣高中生與一般學習者。

詞彙的分析單位與 Form／Meaning／Use 見 [詞彙知識框架](../詞彙知識框架.md)；哪些詞義或表達值得學、材料從哪裡取得及如何查核，見 [材料選擇與準備](../材料選擇與準備.md)。本文件從「目標內容已經初步選定」開始，處理它如何轉成卡片、如何練習與如何評量，不重新建立詞彙理論或選材框架。

---

## 0. 先說結論

詞卡主要適合集中建立**可提取的形式—意義連結**，例如看到 *break the law* 能取得「違法」的意思，或想表達「做出決定」時能提取 *make a decision*。它也能附帶練習拼字、發音、搭配與特定用法，但不能單靠卡片證明學習者已能理解長篇文本、選對語域（register，也就是符合場合與正式度的用語）或完成即時互動。

最低限度的做法是：

1. 每張卡先指定一個要提取的目標，而不是把某個詞的所有知識一次塞進去。
2. 正面提供不直接洩漏答案的提示；學習者必須先回想，再看背面。
3. 背面提供可核對的答案；答錯或不完整時，先看正確答案，再於稍後重新提取。
4. 同一項目分散到不同時段或日期複習，而不是在一次長時間練完後不再出現。
5. 卡片方向與評量方向要符合目標：接收卡不能直接證明產出，文字卡不能直接證明聽辨或發音。
6. 定期用延遲、未見語境或目標任務檢查；不能只看軟體中的「熟練」標記。

研究支持有意詞彙學習、主動提取與分散練習的整體方向，但沒有證明某一種卡片欄位、固定間隔公式或任何間隔重複排程（spaced repetition system, SRS）軟體在所有條件下最好。提示種類、多義詞拆分與排程仍須依目標、程度及實際錯誤調整。

## 1. 方法定義與範圍

### 1.1 方法 ID 與核心流程

| 欄位 | 本方法的紀錄 |
|---|---|
| 方法 ID／名稱 | `PM-LX-CARD-01` 主動提取詞卡與間隔複習 |
| 主要服務對象 | `LX-R` 詞彙接收、`LX-P` 詞彙產出；依媒介與目標另加 `LX-P-T` 或 `LX-P-A` |
| 支援服務對象 | 特定 `GR-R`／`GR-P`、`PR-R`／`PR-P` 或 `PH-R`／`PH-P` 問題可用卡片輔助，但須另證明卡片形式真的對應該能力 |
| 主要學習條件 | `LC-LFL` 語言形式導向學習 |
| 核心實作機制 | `M-RETRIEVE` 主動提取、`M-SPACE` 分散／間隔安排、`M-CF` 答後核對與修正 |
| 主要直接結果 | 指定提示下的詞義或詞形提取更準確、較快，並能延遲保持 |
| 主要外推限制 | 卡片成功不能直接代表未見語境理解、自然產出、語用適切或完整目標任務成功 |

本文件所稱**詞卡（word card／flashcard）**，是把提示與答案分開呈現，使學習者必須先嘗試提取，再核對答案的工具。紙卡、試算表、一般數位卡與 SRS 都可以承載這個流程；工具本身不是方法效果的保證。

### 1.2 什麼不算本方法

以下做法不包含完整的核心流程：

- 同時看到外語詞與翻譯，反覆閱讀但沒有先回想。
- 不論答對答錯都立即滑過，沒有核對或再次提取。
- 只在同一次短時間內重複很多遍，之後不再複習。
- 把整頁筆記放進卡片，卻沒有指出每次要回答什麼。
- 只因軟體宣稱使用 SRS，就假定其選材、答案、評分與排程都有效。

這些做法仍可能提供接觸或複習機會，但不能直接套用本文件對「主動提取＋回饋＋間隔」組合的判斷。

## 2. 建卡前先指定學習目標

同一個詞可以製成方向完全不同的卡。建卡前至少回答四個問題：

1. **要練哪個單位**：單一詞形、詞目、個別詞義、多詞單位、搭配，還是某個使用限制？
2. **要練哪個方向**：看到或聽到形式後理解，還是從意思或溝通目的提取形式？
3. **目標媒介是什麼**：文字、語音，或兩者都需要？
4. **成功需要多精確**：大意相近即可，還是必須拼字、搭配、詞形、語域與發音都正確？

例如，「認得 *make a decision* 的意思」「從『做出決定』提取 *make a decision*」「在句子中選用 *make* 而不是 *do*」「聽到連續語流時辨認這個詞組」是四個不同目標，不應因為都跟同一個詞組有關就視為同一張卡已全部練到。

## 3. 一張卡應包含多大的目標

### 3.1 一次只要求一個可判定的主要答案

「一張卡一個目標」不是指背面只能有一行字，而是正面必須讓學習者知道這次要提取什麼，作答後也能判定成功與否。背面可以補充發音、例句、搭配或相關詞義，但不能把「有看過補充資訊」算成已提取。

| 目標 | 合理的主要答案單位 | 不宜混在同一次提取中的內容 |
|---|---|---|
| 辨認詞義 | 一個指定語境中的詞義 | 同一詞目的所有辭典義項 |
| 自行選詞 | 一個詞或可接受的同義表達 | 拼字、發音、所有搭配與語域判斷一次全算 |
| 學習搭配 | 完整搭配或缺漏部分 | 只答出單一中心詞卻算整個搭配正確 |
| 學習固定表達 | 整個多詞單位 | 把每個組成詞分開背完便宣稱已會整體用法 |
| 學習拼字 | 指定詞形的完整拼字 | 只認得意思 |

### 3.2 多義詞：先分清「選入哪些詞義」與「怎麼呈現」

是否需要學 *break* 的「打破」「違反」與「休息」，先由目標任務與材料決定。本方法只處理已選詞義如何練習。

如果多個詞義在目標情境中需要分別辨認或產出，第一版的預設是**分開建立可判定的提示**：

- 接收卡不要只寫 `break → 打破／違反／休息`，而應加入足以指定當下詞義的短語或句子，例如 *break the law* 與 *take a break*。
- 產出卡可分別用「違反法律」與「休息一下」提示，答案為 *break the law* 與 *take a break*。
- 背面可註明它們共享同一詞形或彼此相關，但每次成功只代表該提示下的詞義或表達被提取。

這不是「每個辭典義項永遠各做一張」的規則。非常接近、在目標任務中不必分辨的用法，可以先合併；罕見或目前不重要的詞義也不必建卡。González-Fernández 與 Webb（2024）發現，為熟悉詞形學習另一個意思，可能和為陌生詞形學第一個意思一樣困難；這支持不要把「已認得這個字」當成已會次要詞義，但該研究沒有直接比較「一張卡列多義」與「分卡」何者更好。因此，分開提示是為了讓練習與評量可判定的專案操作推論，不是已由直接比較確證的最佳格式。

### 3.3 搭配與多詞單位

當學習目標是搭配、慣用語或固定句框時，答案單位應保留必要組合。例如要避免產出 *do a decision*，卡片目標應是 *make a decision*，而不是只背 *decision*。若目標是 `break up with someone` 中的介系詞，可在正面保留其他部分並遮住 *with*；若目標是整個表達的自由提取，正面則不能把關鍵詞都顯示出來。

### 3.4 難以一對一翻譯的詞與詞義卡家族

有些詞找不到一個能涵蓋所有用法的中文對應詞。這不表示應把所有內容塞進同一張英中卡，也不表示每次中文換譯都代表一個獨立英文詞義。建卡前先判斷差異來自哪裡：

| 差異來源 | 判斷方式 | 建卡方式 |
|---|---|---|
| **獨立詞義** | 同一形式在不同語境指向不同概念，原本答案無法合理涵蓋另一用法 | 為目前需要的詞義建立分開的接收或產出卡 |
| **詞性、句法或發音改變** | 例如同形詞作形容詞與動詞時，搭配、句型或讀音不同 | 原則上分開建卡，並在主要答案中要求相應形式 |
| **固定構式或多詞單位** | 整體意思或使用條件不能由單一詞自由推出 | 以完整構式為目標，例如 `grace period`、`in earnest` 或 `at one's wits' end` |
| **同一核心意思的自然換譯** | 中文因對象或情境改用「應付、撐住、承受」等說法，但英文仍維持同一核心關係 | 不因中文詞不同而自動拆卡；背面列核心釋義與數個可接受說法 |
| **語氣、立場或正式度** | 核心指涉接近，但說話者可能表達禮貌、批評、反諷、親暱或委婉 | 若該差異會影響目標任務是否成功，加入答案條件或另建對比卡；否則先放在補充區 |

為避免拆卡後失去各用法之間的關係，本文件把「同一詞目總覽連到數張詞義、形式或構式卡」稱為**詞義卡家族**。這是本文件的操作名稱，不是新的詞彙理論分類。詞目總覽本身可以記錄：

- 詞目、詞性、發音及必要詞形；
- 已選入的詞義或構式，以及它們與目標任務的關係；
- 每項用法的核心釋義、常見中文表達、搭配、語氣、正式度與可靠來源；
- 各用法要產生接收卡、產出卡、語音卡或對比卡中的哪幾種；
- 尚未選入、目前不要求學習的詞義。

詞目總覽是管理與查核資料，不因學習者看過整張總覽就算已提取其中所有內容。每張實際練習卡仍只指定一個可判定的主要反應。背面可以採「**核心意思＋本句的語氣或使用條件＋必要構式**」的格式，不必強迫選出唯一中文詞。例如 *cope* 的核心可寫成「在困難或壓力下設法承受、處理下去；常見 `cope with + 困難事物`」，並把「應付、撐住、承受」列為依語境可接受的中文說法，而不是做成三個獨立詞義。

第一版可依下列順序決定是否拆卡：

1. 先排除不服務目前目標任務的罕見、專業或歷史用法。
2. 若詞性、發音、必要構式、核心概念或任務所需的語氣判斷不同，優先分開。
3. 若差異只來自中文為了自然表達而換詞，保留同一核心答案，不因翻譯數量增加卡片。
4. 若仍無法判斷，先用一張可清楚判分的語境卡；只有在實際錯誤顯示兩種用法需要不同練習或評量時再拆。

這套詞義卡家族是依詞彙知識分析與本文件的可判定原則形成的操作推論。現有研究支持不能把熟悉詞形當成已掌握所有詞義，但尚未直接證明上述欄位與拆卡順序一定優於簡單翻譯卡；使用時仍須比較製卡負擔、延遲保持與未見語境表現。

## 4. 接收、產出與媒介方向

### 4.1 接收卡

接收卡從目標語形式出發，要求取得意思或功能：

> 正面：*break the law*  
> 作答：說明或選出當下意思  
> 背面：違反法律；附一個已核對例句

這主要對應 `LX-R`。若正面只有文字，它不能直接測試從語音辨認；要練聽辨，正面應使用音訊，必要時在作答後才顯示文字。

### 4.2 產出卡

產出卡從意思、情境、圖片或母語提示出發，要求提取目標語形式：

> 正面：搭配填空；從 *make*、*do* 選一個：*The committee must ______ a decision by Friday.*<br>
> 作答：*make*<br>
> 背面：*make a decision*；完整句：*The committee must make a decision by Friday.*

這張受控卡只檢查學習者能否為 *decision* 選出目標動詞，不要求先從一段開放情境猜測人物接下來要做什麼。若正面只寫「討論完所有方案後，現在需要……」，學習者也可能合理回答「結束會議」或「向主管報告」；此時答不出 *make a decision*，不能直接解讀為尚未學會該搭配。若真正目標是從溝通意圖自由提取完整說法，則應明示該意圖，並依第 6.2 節接受符合情境的其他表達，將「溝通成功」與「指定搭配提取」分開記錄。

這主要對應 `LX-P`；要求寫出時加上 `LX-P-T`，要求說出時加上 `LX-P-A`。若還要判斷對象與場合是否適合，另涉及 `PR-P`，不能只用單一詞形答對代替語用評量。

### 4.3 是否要雙向練習

接收與產出不是同一件事。若目標只是在閱讀中辨認低重要性詞彙，接收卡可能已足夠；若目標是口說或寫作提取，至少要有產出方向。兩個方向都重要時，可以建立兩張關聯卡，或由同一筆資料產生兩種提示，但練習紀錄與成效仍應分開。

Terai、Yamashita 與 Pasich（2021）發現，提取方向的效果會隨學習者程度改變：其研究中，程度較低者在目標語到母語方向表現較好，程度較高者則在母語到目標語方向較好。這是一項特定日籍英語學習者研究，不能化成所有人的固定分級規則；較穩妥的做法仍是依目標方向建卡，再用實際表現調整負荷。

### 4.4 從九個詞彙知識面向選擇卡片操作

[詞彙知識框架](../詞彙知識框架.md) 將 Nation 的 Form／Meaning／Use 展開為九個詞彙知識面向，每一面向又可從接收與產出方向分析。這套 9×2 結構是製卡前的**需求與缺口檢查表**，不是要求每個詞製作十八張卡的固定處方。實作時應先問：「目標任務需要這個詞的哪項知識，而學習者目前缺少哪一部分？」再選擇最小而可判定的卡片或其他練習。

| 詞彙知識面向 | 可用的卡片操作 | 判讀邊界與選擇原則 |
|---|---|---|
| **Form—口語形式** | 接收時播放單詞或含目標詞的語流，要求辨認形式或取得意思；產出時要求說出目標形式並核對可靠錄音或可理解度 | 純音訊接收卡若要求回答意思，會同時動用口語形式與形式—意義連結；聽懂孤立錄音不等於能在自然語流辨認。只有實際說出並獲得適當核對，才能直接練發音產出 |
| **Form—書寫形式** | 從意思或情境寫出詞形；或在易混形式中辨認正確拼法 | 只在心中想答案再翻面，不能證明拼字正確；看到目標詞後回答意思，也不能單獨證明能自行拼出 |
| **Form—詞的組成部分** | 拆解字根、字首與字尾，例如辨認 *un-*、*break*、*-able* 各自提供的意思；或依句子提取正確的複數、時態，以及由字首或字尾形成的相關詞 | 不規則複數、時態及重要相關詞可在有獨立缺口時建卡；不能因會基本詞就推定會由同一詞根組成的一整組詞，也不鼓勵任意拼出實際不存在的形式 |
| **Meaning—形式與意義的連結** | 從文字或語音取得當下意義，或從意義、圖片與情境提取形式 | 這是一般接收與產出詞卡最直接的目標；提示媒介與答案媒介仍須符合目標任務 |
| **Meaning—概念與指涉範圍** | 為任務相關且概念確實不同的詞義分別建卡；用適用與不適用的例子及對比情境檢查邊界 | 不機械地為所有辭典義項或中文譯法建卡。難以一對一翻譯時，先用解說與多個例子建立概念，再以「核心意義＋必要限制或情境」提示提取 |
| **Meaning—聯想** | 用分類、配對或情境選詞，比較同義詞、反義詞、較大的類別與其中的具體成員，以及意思的強弱差異；也可從概念差異提取適當詞 | 列出 N 個相關詞不能證明知道它們的差別；若目標是產出，需在新情境自行選回合適形式，而不只是從選項中認出 |
| **Use—文法功能** | 以句子或溝通情境要求選用詞性、動詞後是否直接接受詞、後接 `to V` 或 `V-ing` 等形式，以及正確的複數或時態 | 固定介系詞、`to V`／`V-ing` 等有時也可視為搭配的一部分；卡片可跨面向，但仍應只有一個可判定的主要反應，並記清楚失敗發生在哪裡 |
| **Use—搭配** | 將無法逐字猜出整體意思的多詞單位當作完整目標；依需要為固定介系詞、動詞—名詞等常見組合建立接收或產出卡 | 優先考慮任務價值、母語干擾或實際錯誤、出現頻率，以及這個組合是否相對固定。只需理解的搭配不必一律做產出卡 |
| **Use—使用限制** | 用情境選擇題判斷頻率、語域（適合哪類場合的說法）、地區、社會群體及特定場合；用情境產出題檢查能否依對象與目的選詞 | 選擇題只直接支持接收判斷；要主張能產出，還需在未顯示候選詞的新情境選用。近義詞不能只因核心意思相近就任意互換 |

將九個面向轉成卡片時，再遵守四項共同規則：

1. **不追求逐格製卡**：只處理目標任務需要、材料值得學且學習者尚未穩定掌握的分析位置。
2. **答案媒介決定能直接觀察什麼**：書寫答案才能直接檢查拼字；口說答案並接受可靠核對，才能直接檢查發音；選出答案不能直接證明自由產出。
3. **一張卡可以動用多個面向，但只設一個主要反應**：例如依過去時間情境寫出 *broke*，會同時動用意義、書寫形式、過去式變化與文法功能；判分時仍應指出主要目標及錯誤來源，而不是一次答對便宣稱四項皆已掌握。
4. **卡片不適合時換方法**：語域、近義詞細微差異或即時選詞若無法用簡短提示可靠判斷，可先用對比講解或分類卡，再升級到改述、寫作、口說或完整任務；不必為了覆蓋九面向而勉強塞進詞卡。

## 5. 提示與答案形式怎麼選

### 5.1 先分開三項決定

選擇卡片格式時，不能只問「要不要使用母語或圖片」，而要先分開三項決定：

1. **提取方向**：從目標語形式取得意義，還是從意義或溝通目的提取目標語形式？
2. **正面如何呈現**：使用文字、音訊、圖片、定義，還是包含上下文的情境？
3. **答案如何表達與判定**：要求說明意義、選擇情境、寫出詞形，還是說出詞形？

同一項元素在不同方向可以有不同功能。例如母語翻譯可作為產出卡正面的提示，也可作為接收卡背面的核對答案；情境可以保留目標詞來協助辨認當下詞義，也可以挖空目標詞來要求產出。若不先分開這三項決定，就容易把不同的學習目標誤當成同一種卡片。

| 提取方向 | 正面的基本內容 | 學習者的主要答案 |
|---|---|---|
| 接收：形式 → 意義 | 目標語文字或音訊；可附不洩漏答案的語境 | 說明、選出或以其他方式表示當下意義或功能 |
| 產出：意義 → 形式 | 母語、圖片、目標語定義、情境或溝通目的 | 說出或寫出指定的目標語詞形或多詞單位 |

### 5.2 接收卡：目標語形式如何呈現

接收卡要先決定學習者在真實任務中會遇到什麼形式。正面不是用母語或圖片代替目標詞，而是呈現需要辨認的目標語形式。

| 正面呈現 | 較適合的目標 | 主要風險 |
|---|---|---|
| **單獨的目標語文字** | 快速建立書面形式與核心意義的連結 | 單獨形式可能無法指定詞義或詞性，例如 *content* 可指「內容」或「滿足的」；即使看到 *conscience* 能答出意思，也不能證明聽到時認得 |
| **含目標詞的文字語境** | 多義詞、搭配及依語境改變的意義 | 可能只靠其他線索猜中，例如從 *The burglar stole jewelry from the house.* 的 *stole jewelry* 猜出 *burglar*，卻沒有建立穩定的形式—意義連結；固定使用同一句也可能只記住整句 |
| **單獨的目標語音訊** | 從語音形式取得意義、區分易混音 | 清楚、可重播的孤立錄音不能證明能在連續語流中認出；例如孤立聽懂 *associate*，不代表在自然句速中仍能切出該詞。答出意思也不能測正確發音產出 |
| **含目標詞的連續語流** | 真實聽力中的詞彙辨認 | 音質、語速、口音與上下文會同時改變難度。例如沒答出 *content*，可能是未切出詞與詞的界線（word boundary，詞界）、沒聽出重音、不了解當下詞義或整句太難，不能立即判定只是詞彙遺忘 |

「靠情境答對，卻沒有從記憶提取詞義」的風險有直接研究支持，但目前不能給所有詞卡一個通用的高估比例。van den Broek et al.（2018）在三個實驗中比較可由句意推得答案的豐富情境，以及必須從記憶提取詞義的低資訊情境：前者提高練習當下的理解，成功提取及提取後回饋則在之後的形式、意義回想與新情境辨認上較好。這表示「原句中答對」和「已建立可獨立提取的形式—意義連結」確實可能分離。

不過，這不是「情境線索越少越好」的普遍規則。Webb（2008）發現，在閱讀中遇到較能提示詞義的語境，有利於之後的詞義測驗；van den Broek et al.（2022）使用完整故事時也發現，若前期學習不足而使提取經常失敗，豐富情境可能優於低資訊情境；加強前期學習並提供回饋後，兩者則沒有差異。研究任務、初始掌握、提取成功率、回饋與後測方式都會改變結果，因此本文件只把這項風險列為需要檢查的機制，不自行估計發生率。

接收卡的答案可以用母語釋義、目標語解釋、圖片、動作、選項或情境判斷來表示；選哪一種，應以能否清楚判定目標詞義為準。若要求自由說明，製卡時要先列出必要語意特徵與可接受說法；若使用選項，答對只證明能在該組選項中辨認，不能直接視為已能無提示回想意義。

Gyllstad et al.（2023）在瑞典多語中學課堂比較以目標語定義、瑞典語翻譯，以及瑞典語加其他已知語言呈現英語詞義。含翻譯的條件在立即後測有小幅優勢，延遲後測則沒有差異；後測是看到英語詞形後回想意義，並允許學生用不同語言、圖畫等方式回答。這項研究支持母語翻譯可以作為低負擔的詞義呈現方式，但不是直接比較所有詞卡正面，也不能證明接收卡必須用母語作答。

### 5.3 產出卡：意義如何提示目標語形式

產出卡的正面要表達預定意義或溝通目的，同時避免直接顯示要提取的目標形式。沒有一種提示對所有詞彙、程度與目標都最好。

| 正面提示 | 較適合的情況 | 主要風險 |
|---|---|---|
| **母語翻譯** | 快速建立較清楚的意義—形式連結；初學者；有合適對應詞的概念 | 一對一翻譯可能掩蓋詞義範圍，例如只用「採用」提示 *adopt*，沒有練到「收養」；反過來，「適當的」也可能對應 *appropriate*、*suitable* 等多個合理詞，未必能唯一指定答案 |
| **圖片或實物** | 可清楚描繪的物體、動作或空間關係；不希望依賴文字翻譯 | 圖片適合 *broom* 等具體物件，卻很難精確表示 *abstract*；一張電池照片通常也只提示 *battery* 的「電池」義，不能代表其他詞義。圖片看來直觀，還可能使學習者高估掌握程度 |
| **目標語定義** | 已能讀懂定義；需要提示概念特徵或區分近義詞 | 定義中的詞可能比答案更難；例如用 *happening repeatedly but with breaks* 提示 *continual*，學習者若不懂 *repeatedly* 就無法作答。定義措辭若未清楚區分 *continual* 與 *continuous*，也可能容許兩個答案 |
| **挖空的情境或溝通目的** | 多義詞、搭配、語域、實際選詞及較接近產出的練習 | 可能有多個合理答案，例如 *The committee decided to ___ the new policy.* 可填 *adopt*，也可能依脈絡填 *approve* 或 *accept*；有時只靠詞性、首字母或搭配線索就能猜中，卻未真正掌握目標詞義 |

Carpenter 與 Olson（2012）比較從圖片或英語翻譯提取斯瓦希里語詞形。圖片在特定練習與提醒條件下可能有利，但學習者也容易對圖片條件過度自信。因此，圖片可作為具體概念的候選提示，不能僅因它看起來直觀就推定比母語更有效；仍須用實際提取與延遲測驗判斷。

產出提示若可能對應多個合理詞彙，應增加足以指定目標的語意、搭配、詞性或情境線索，或者事先列出可接受答案。若卡片目標是自由表達而非指定詞彙，就不應因學習者用了另一個合適說法而判錯。

### 5.4 如何取得與檢查情境提示

情境提示可以優先取自目標任務中實際會遇到的文章、對話、題目或文件；沒有合適實例時，再使用可靠學習辭典、語料庫或教材例句。AI 可以協助產生候選句，但仍須依第 8 節查核詞義、搭配、文法與自然度，不能因句子通順就直接採用。

若正面要呈現的是**溝通目的**，不要只留下脫離情境的中文翻譯。先從目標任務記錄「誰對誰、要達成什麼、使用何種媒介、正式度與錯誤後果」，再把本次真正影響選詞的條件寫成簡短提示。例如要提取 *apology*，可寫成「你遲到並影響會議，現在要用較正式的名詞向主持人表達歉意」，而不是只寫「道歉」。即使如此仍可能有多個自然答案，因此仍須依下方規則處理替代說法。

同一個情境不必同時承擔初次講解、提取練習與遷移評量。較低負擔的做法是依階段準備不同版本：

| 階段 | 情境的工作 | `content` 的示意做法 |
|---|---|---|
| 初次建立詞義 | 明確指出目標詞義並提供可靠答案，避免錯誤猜測 | *She felt content with the result.*；背面說明此處為形容詞「滿足的」，並與名詞「內容」分開 |
| 提取練習 | 提供足以指定詞義與用法、但不能直接推出答案的最低必要線索 | 換成 *They seemed content with what they had.*，要求先回想 *content* 在句中的意思，再看答案 |
| 遷移檢查 | 使用未見句子、說話者或文類，確認不是只記得原句；這通常另做抽樣評量，不要求日常詞卡軟體自動完成 | 使用另一個未見語境，如 *He was content to wait.*，檢查能否仍取得相同核心意義 |

候選情境至少通過以下檢查：

1. **目標對齊**：接收卡保留目標形式並指定要辨認的詞義；產出卡遮住目標形式，並說清楚要表達的意義、對象或場合。
2. **其餘內容可理解**：除了目標詞，句中不應塞入多個學習者不懂的詞或過難句法，否則答錯原因無法判定。
3. **不直接洩漏答案**：對接收卡，可暫時遮住目標詞；若只讀其他部分便能完整回答詞義，這句較適合初次講解，不適合作為提取是否成功的唯一證據。
4. **處理合理替代答案**：對產出卡，先檢查是否有其他自然答案。例如 *The committee decided to ___ the new policy.* 除了 *adopt*，依脈絡也可能接受 *approve* 或 *accept*。可以增加語意、搭配、詞性或字首等限制並記錄提示強度，也可以列出合理替代答案；不能為了維持單一答案而把正確表達判錯。
5. **核對自然度與來源**：至少用可靠辭典、語料或原始材料核對目標詞義與搭配；高後果內容另由合格人員確認。
6. **更換情境再測**：練習可從熟悉句開始；若要宣稱已能遷移，延遲評量須另含未見語境。若只在原句成功，就把結果記為原卡保持，不宣稱已能跨情境提取。

**普通詞卡軟體的最低做法**如下：

1. 日常仍用固定正反面卡片進行間隔複習；軟體中的答對與到期紀錄只解讀為「原卡提示下的延遲保持」。
2. 到檢查時再從已練項目抽取一部分，不必為每張卡每次製作新句。接收項目從可靠學習辭典、語料、教材或新的目標任務材料取得一個未放進牌組、但使用相同目標詞義的新語境；產出項目則換一個對象、目的或場合，重新要求表達同一詞義。語音目標可換成另一段錄音或說話者。
3. 把這批材料放在詞卡軟體以外的簡單表格或測驗紙中，作答後才核對答案並記錄「未見語境成功／失敗」。若軟體支援獨立牌組或暫停卡，也可由教師或其他協助者事先放入、到檢查日才首次顯示；顯示過一次後，它就不再是未見材料。
4. 自學者若沒有他人準備題目，可在檢查當下才從可靠來源抽取新例句；也可請 AI 產生候選語境，但應在作答後核對詞義與自然度，不能讓未查核的 AI 句子或評分成為高後果判斷的唯一依據。

因此，只有固定正反面的軟體確實無法單獨完成嚴格的未見語境評量。這不妨礙它負責日常提取與排程；只要把遷移檢查視為低頻、抽樣且獨立的評量活動即可。若不另做這一步，仍可報告原卡的延遲保持，但證據邊界應停在原卡，不能把軟體成熟率解讀為跨語境能力。

這些是依現有研究與本文件評量原則形成的操作規則，不是已證明唯一最佳的製句公式。實作時應記錄情境來源、是否經過改寫、允許哪些答案，以及提示被撤除或更換後的表現。

### 5.5 共同選擇順序

第一版採以下選擇順序：

1. 先指定接收或產出方向，再選正面呈現與答案方式；不因「全外語」看來較進階就一律排除母語。
2. 接收卡先對齊真實任務中的文字或語音形式；產出卡再依概念是否具體、是否多義及是否重視搭配或語域選擇意義提示。
3. 正面只保留完成該次提取所需的線索；發音、例句、相關詞義等補充資訊放在作答後。
4. 事先寫明可接受答案與通過條件；選項、首字母或固定原句等提示存在時，不把成功外推成無提示提取。
5. 若學習者經常不是忘記，而是被呈現方式或答案標準誤導，就修改卡片，而不是單純提高重複次數。

### 5.6 從簡譯到其他活動的分層決策

母語翻譯可快速建立形式—意義連結，尤其適合作為初學時的低負擔提示；但它是否足夠，取決於母語概念與目標語概念的對應程度，以及目標任務要求辨認還是精確使用。Kim、Lee 與 Lee（2024）的後設分析發現，第一語言詞義註解相較第二語言註解的優勢主要見於立即詞彙後測，對延遲詞彙後測與閱讀理解的相對優勢較不明確；Boers（2022）也指出，詞義註解研究因設計多樣、報告透明度及測量內容等問題，仍有許多只能暫時回答的設計問題。這些結果支持把簡譯當成可用起點，不支持「簡譯永遠足夠」或「完整解說永遠較好」。

第一版依下列條件逐層增加材料與練習；一旦前一層已能滿足目標，就不為追求完整而自動升級：

| 層級 | 何時使用 | 最低做法 | 不能據此宣稱 |
|---|---|---|---|
| **簡譯連結** | 母語概念大致等價，而且任務只需建立基本辨認或指定形式的初步提取 | 使用簡短母語提示，建立接收或產出方向的形式—意義卡 | 不能因答出翻譯便宣稱掌握全部詞義、搭配與使用條件 |
| **簡譯＋關鍵區辨** | 近似翻譯可用，但少掉一項重要限制便容易過度泛化或誤解 | 保留簡譯，再補一項最會影響任務的概念邊界、詞性、必要構式或語域條件 | 不能把一項區辨當成完整定義 |
| **情境或對比判斷** | 容易與母語概念、另一詞義或近義詞混淆，而且差異能用清楚情境判定 | 使用適用／不適用例、近義詞對比或情境選擇；若要練產出，再撤除選項測一次 | 選對既有選項只直接支持該組條件下的接收判斷 |
| **先建構概念，再以卡片保留可測部分** | 概念抽象、跨語言邊界不等價，或需要多個實例才能理解共同特徵 | 先閱讀已核對的解說與多樣例子；卡片只提取能清楚判分的核心意義、限制、構式或代表性對比 | 不能要求單張卡證明學習者已掌握整個概念範圍 |
| **改用未見語境或完整任務** | 目標涉及語域、語用、自由產出、長篇理解或即時互動，短卡無法可靠呈現成功條件 | 保留卡片作局部複習，另用未見句子、改述、寫作、口說、互動或目標任務評量 | 不能用卡片成熟率代替跨情境或完整任務表現 |

這個分層是把詞彙知識分析、詞卡適用邊界與低負擔預設整合成可修改的**專案操作推論**，不是已由研究直接比較並確證的最佳卡組。Lei 與 Reynolds（2022）整理的詞卡研究多測量形式與意義，較少測量詞彙使用，而且卡片對概念範圍、文法模式與搭配只能部分處理；因此，系統若依九面向推薦卡片，仍須把「建議卡片」「需要先解說」與「應改用其他活動」分開，不可假定每個知識缺口都適合製卡。

## 6. 背面答案與回饋

### 6.1 背面至少要能判定對錯

背面依目標提供必要資訊：

- **詞義目標**：指定語境中的意思，而不是整份辭典條目。
- **產出目標**：目標詞或多詞單位，並列出事先認可的替代答案。
- **拼字目標**：完整書寫形式。
- **口語形式目標**：可核對的音訊；音標或文字只能作輔助。
- **搭配或句型目標**：完整搭配與必要句法資訊。
- **使用限制目標**：簡短標示對象、場合、正式度或地區；高風險內容需有可靠來源。

背面可以附一個例句，但例句不是越多越好。資訊過多會增加製卡與複習負擔，也使學習者難以知道這次錯在哪裡。其他詞義或延伸用法可以另做卡片，或放在不影響主要判定的補充區。

### 6.2 產出卡答出另一個合理詞時怎麼判斷

這個情況常在學習者原本已經知道一種說法，後來又陸續學到意思相近的其他說法時出現。不同卡片若使用相同或過於簡略的母語提示，原先學會的詞和新詞便可能同時符合正面的要求；詞彙增加後，反而更難猜中製卡時設定的單一答案。

例如，產出卡若只用「處理問題」作提示，學習者可能回答 *handle the problem*、*deal with the problem* 或 *address the problem*。這不一定表示學習者記錯；也可能是正面沒有提供足以區分答案的條件。此時不宜讓詞卡軟體的單一預設答案直接決定對錯，而應依序判斷三件事：

1. **在卡片寫出的情境中，答案是否能達成溝通目的**：檢查意思、文法、搭配、語域及對象是否合適。若都合適，可先記為「溝通成功」。
2. **這張卡是否明確要求指定詞或構式**：若目標是自由表達，合理替代詞應列為可接受答案；若目標是提取 *cope with* 等指定項目，回答 *handle* 可同時記為「溝通成功，但指定詞未提取」。兩者不是同一項成績。
3. **正面是否真的足以指定預期答案**：如果多個詞在現有提示下同樣自然，這是卡片規格不足，不能把未猜中製卡者心中的答案當成語言錯誤。應先修改或停用該卡，再決定是否需要更多練習。

確認問題後，可依真正目標選擇下列做法：

| 真正目標 | 做法 | 例子與判定 |
|---|---|---|
| **只要能表達意思** | 在背面列出已查核的合理答案；有新答案時再依語意、搭配與語域判斷是否加入 | 「處理這項申訴」在指定情境中若 *handle the complaint* 與 *deal with the complaint* 都自然，兩者皆可算通過 |
| **提取指定詞或搭配** | 加入能反映真實用法的最低必要條件，例如語意特徵、搭配、句法、對象、正式度或溝通目的 | 「在悲傷中設法撐住」加上 `______ grief`，要求提取 *cope with*；答 *handle* 可記為溝通合理，但指定構式未提取 |
| **學會近義詞間的選擇** | 另做對比或分類卡，直接要求判斷各詞的典型條件，不讓數張相同中文提示互相競爭 | 比較 *cope with grief*、*handle a complaint* 與 *address an issue* 分別凸顯的困境承受、具體處理與正式著手處理 |
| **提示無法自然指定唯一詞** | 改成接收卡、完整搭配／句塊卡，或回到情境產出活動；不要勉強保留單一答案的產出卡 | 若只有「處理」且目標任務也不要求特定詞，就不以首字母強迫學習者猜 *address* |

首字母、字數或任意中文代號可以降低答案數量，但除非目標本來就是受提示的拼字或指定形式提取，否則這些線索不能證明學習者已學會真實選詞。普通詞卡軟體只能接受單一答案時，可以在背面或備註欄列出合理替代詞，作答後由學習者分別記錄「溝通適切」與「指定詞提取」；若軟體無法保存兩種結果，至少不要把合理替代答案記成一般語言錯誤。

這套判斷是依本文件的目標對齊與評量原則形成的操作規則。它用來避免含糊提示造成錯誤診斷，不表示每組近義詞都有固定邊界，也不表示對比卡已被直接證明一定優於分開學習。詞義與使用條件仍須由可靠辭典、語料或目標任務材料核對，並以未見情境中的選詞表現檢查是否真正學會。

### 6.3 作答後怎麼處理

1. 先判定主要答案是正確、不完整或錯誤。
2. 錯誤或不完整時，看清楚正確答案並說出／寫出一次。
3. 在稍後幾張卡之後再次提取，避免只靠剛看過的短暫記憶。
4. 若同一錯誤反覆出現，判斷是內容太難、提示含糊、答案標準不合理，還是確實尚未建立連結。

Nakata（2015）比較立即與延遲回饋，在控制回饋到測驗的時間後，沒有發現明確的回饋時機優勢。因此，本文件把答後立即顯示答案列為低操作負擔的預設，而不宣稱它在所有條件下比延遲回饋更有效。真正不可省略的是錯誤後能取得可靠答案，並有機會再次提取。

## 7. 間隔與排程

### 7.1 間隔的核心不是某組固定天數

間隔安排是讓同一項目在不同時間點再次出現。Kim 與 Webb（2022）的後設分析支持分散練習對第二語言學習的整體價值，也顯示效果會受到後測時間、學習內容與練習安排等條件影響。因此，本文件不把「第 1、3、7、14 天」或任何固定公式寫成普遍最佳排程。

一個不依賴特定軟體的最低流程是：

1. 新卡第一次作答後，答錯項目在同一時段稍後再提取，不立刻連續翻看。
2. 當次能提取的項目移到另一個時段或日期再測。
3. 延遲後仍成功，逐步拉長下次間隔；失敗則縮短間隔並檢查卡片品質。
4. 每次先完成到期複習，再決定是否加入新卡；若到期量持續超過可負擔時間，減少或暫停新卡。
5. 定期抽取未見語境或完整任務評量，不讓排程只對卡片本身最佳化。

紙卡可以用「待學—短期複習—較長間隔」等卡堆實作；數位系統則可以根據答對、答錯或信心評分調整下次日期。這些都是排程工具，仍須另記其規則與使用方式。

### 7.2 SRS 能與不能保證什麼

SRS 會依學習者對卡片的反應安排未來複習時間，主要目的是在忘記風險與複習成本之間取捨。它可能降低手動排程負擔，但不能自行保證：

- 選入的是值得學的內容；
- 卡片答案正確、自然且符合目標語境；
- 自評的「簡單／困難」準確；
- 排程參數符合預定保持時間；
- 卡片成績會遷移到未見語境或完整任務。

因此，「使用 SRS」只描述排程機制，不能代替對完整方法或特定軟體的效果驗證。

### 7.3 重複次數不是越多越好

Nakata（2017）顯示同一時段內增加成功提取次數可能改善延遲保持，但研究也提醒必須考慮總練習時間。已能穩定提取的項目若繼續集中重複，可能排擠較需要練習的內容。實作上應以延遲後能否提取、是否達到目標速度及總時間負擔決定是否繼續，而不是追求每張卡固定重複很多次。

Kim 與 Webb（2023）直接比較填空與詞卡的集中／間隔練習，兩種活動在兩週延遲後測都受益於跨日間隔；這支持跨日複習可用於詞卡，但也顯示間隔效果會和活動類型、後測時間互動，不能只靠單一立即測驗決定排程。

## 8. 材料來源、查核與 AI

卡片內容的選擇、來源與準備依 [材料選擇與準備](../材料選擇與準備.md) 處理。最低要求是保留：

- 目標詞義或表達為何與任務相關；
- 原始來源或可靠參考資料；
- 詞義、搭配、例句、發音與使用限制的查核狀態；
- 這張卡練接收或產出，以及文字或語音；
- AI 是否參與擷取、改寫、翻譯、生成例句或評分。

AI 可以先產生候選卡、例句或可接受答案，但輸出流暢不等於正確。尤其是多義詞、近義詞、搭配、語域、罕見用法及高後果詞彙，應對照可靠辭典、語料、官方資料或合格人員。AI 若自動判定自由產出答案，也要檢查它是否錯收不適切答案或錯拒合理變體。

## 9. 成效評量

### 9.1 不以卡片數量代替能力

「新增 500 張」「複習 30 天」或「成熟率 90%」是過程紀錄，不是語言成效。至少分開觀察：

| 指標 | 要回答的問題 |
|---|---|
| 練習正確率 | 在原卡提示下是否答對？ |
| 反應時間 | 是否快到足以服務目標任務？ |
| 延遲保持 | 隔一段時間後是否仍能提取？ |
| 提示撤除 | 沒有選項、首字母或原例句時是否仍成功？ |
| 未見語境遷移 | 換句子、說話者、文類或題目後是否仍理解或產出？ |
| 目標任務表現 | 詞彙改善是否真的減少閱讀、聽力、寫作或互動中的失敗？ |

這些指標不必全部由同一套軟體自動取得。日常詞卡提供練習正確率、反應時間與原卡的延遲保持；提示撤除、未見語境與目標任務表現可以依第 5.4 節另做低頻抽樣評量。兩類結果分開記錄，才能看出「記得這張卡」是否已開始轉成「能在其他情境使用」。

### 9.2 評量方向必須對齊

- 只做目標語到母語卡，至少以同方向的延遲意義回想評量；不能直接宣稱會自由產出。
- 產出卡要用意思或新情境提示，不能把目標詞留在題目中。
- 多義詞需分別抽測目標詞義，不能答出最常見義就算整個詞已掌握。
- 拼字或發音若是成功條件，就要單獨評量，不能由詞義答對推定。
- 遷移測驗的材料不能全是原卡例句，否則可能只測到句子記憶。

## 10. 證據對照

### 10.1 完整方法與相近活動的直接證據

| 來源 | 研究實際支持的範圍 | 不能直接推出的結論 |
|---|---|---|
| Webb, Yanagisawa, and Uchihara（2020） | 統合詞卡、詞表、寫作與填空等有意詞彙活動；分別分析意義回想與形式回想結果 | 不能證明所有詞卡欄位、排程、詞彙種類或軟體同樣有效 |
| Kim and Webb（2023） | 直接比較詞卡與填空在集中或跨日間隔下的學習；延遲後測顯示兩種活動都受益於間隔 | 不能由一天間隔推成所有保持期間的最佳排程 |
| Terai, Yamashita, and Pasich（2021） | 比較兩種提取方向，顯示程度可能調節方向效果 | 不能建立所有語言配對都適用的固定程度分界 |
| Gyllstad et al.（2023） | 多語中學課堂比較以目標語定義或一種以上已知語言翻譯呈現詞義，並以形式到意義的回想測驗評量 | 不能證明翻譯或全目標語呈現普遍較佳，也不是各種詞卡正面的直接比較 |
| Carpenter and Olson（2012） | 比較圖片與母語翻譯提示，並觀察學習判斷偏差 | 不能外推到抽象詞、多義詞或所有年齡與程度 |
| González-Fernández and Webb（2024） | 比較主要與次要詞義的有意形式—意義學習難度 | 沒有直接比較多義詞應合卡或分卡 |
| van den Broek et al.（2018, 2022） | 直接比較可由情境推論詞義與必須從記憶提取的練習，並檢查回饋、初始掌握及單句／完整故事等條件 | 研究結果隨提取成功及任務而變，不能推出情境線索一律越少越好 |
| Webb（2008） | 比較閱讀時較多或較少詞義線索的語境，較豐富的線索有利於詞義學習結果 | 屬閱讀中的附帶學習，不能直接決定詞卡應保留多少線索 |

### 10.2 組成機制的間接證據

- **間隔**：Kim 與 Webb（2022）支持分散練習的整體方向，但最佳間隔仍依學習內容、測量與保持時間而變。
- **重複提取**：Nakata（2017）支持同一時段內成功提取次數與延遲保持的關係，但不能不計時間成本地要求無限重複。
- **回饋**：Nakata（2015）顯示在其控制條件下，立即或延遲回饋的差異有限；這支持把可靠答案與再次提取視為核心，不把特定回饋秒數當成普遍關鍵。

### 10.3 尚未解決的問題

本版尚不能為下列問題提供普遍答案：

- 每一類詞彙最適合母語、圖片、定義還是情境提示；
- 多義詞在什麼相似程度下應合卡或分卡；
- 一張卡附多少例句、發音、詞形與搭配最有效率；
- 對特定學習者與保持期間，哪個 SRS 演算法或參數最佳；
- 自評難度、反應時間或自動評分應如何共同決定排程；
- 卡片進步在多大程度上會遷移到自由口說、寫作、長篇理解或語用適切。

遇到這些問題時，應把選擇寫成可修改的操作假說，再用延遲與遷移表現檢查，而不是把軟體預設值當成研究共識。

## 11. 操作負擔、失敗模式與調整

詞彙項目的[學習負擔](../詞彙知識框架.md#65-學習負擔還有多少不能由既有知識直接推出)描述達到指定掌握程度還要補足多少內容；實際採用詞卡時，還要另外計入準備、練習、維護與評量所花的時間。最容易製作的簡譯卡可能降低第一次開始的成本，卻可能因概念過度簡化、提示含糊或答案無法判定而增加後續修正；反過來，完整解說若對任務沒有必要，也可能在一開始就造成不值得的負擔。

### 11.1 分開記錄五類操作成本

本文件先用下列五類記錄實際負擔，不把它們宣稱為 Nation 原有分類，也不預設可以脫離個案直接換算成一個通用分數：

| 成本 | 包含什麼 | 可觀察紀錄 |
|---|---|---|
| **初次理解與概念建構** | 理解詞義、概念邊界、詞義間關係及必要使用條件 | 初次說明與閱讀例子的時間；需要幾次澄清；能否說明關鍵區辨 |
| **準備、查核與製卡** | 尋找可靠釋義、例句、音訊與搭配，決定詞義單位、方向、提示及可接受答案 | 人工與工具花費時間；來源數量；需人工修正的候選卡比例 |
| **排程複習** | 新卡初學、到期複習、答後核對及失敗後再次提取 | 新卡與複習卡分開計數；實際總分鐘；各卡型反應時間與失敗次數 |
| **錯誤概念與卡片修正** | 修正過窄或過寬的翻譯、含糊提示、不合理單一答案、失效例句及重複卡 | 修改、停用或拆卡次數；反覆失敗是否來自知識缺口或卡片問題 |
| **未見語境與目標任務評量** | 準備及執行提示撤除、未見句子、不同說話者或完整任務檢查 | 抽樣題數與準備時間；未見語境及目標任務的成功與失敗 |

卡片張數可以描述牌組規模與原子化的提取目標，但不能直接當成等值負擔：一張新的抽象概念產出卡、一張已成熟的簡單接收卡，以及一張需要播放音訊並人工核對發音的卡，所需時間並不相同。規劃步調時，至少以**實際或預期總分鐘**為主要指標，並分開報告新卡、到期複習、反覆失敗與卡片維護；累積個人資料後，再用各卡型的反應時間、失敗率及再次提取次數校正預估。這是用來比較方法可行性的操作估計，不是語言能力或一般化學習難度分數。

### 11.2 常見失敗模式與低負擔調整

| 觀察到的問題 | 先檢查 | 低負擔調整 |
|---|---|---|
| 卡越積越多，無法完成到期複習 | 新卡量、重複內容、低價值詞義 | 暫停新卡；刪除或擱置低優先項目；合併重複材料 |
| 看卡會，真實情境不會 | 提示是否過強；例句是否一直相同；評量是否只測原卡 | 撤除提示；加入未見情境；回到完整任務檢查 |
| 同一張卡反覆錯 | 提示是否含糊；答案是否有多個合理版本；內容是否過難 | 改寫提示、列可接受答案、拆小目標或暫緩該卡 |
| 經常答出另一個意思相近的詞 | 替代詞在該情境是否自然；目標是溝通成功、指定詞提取，還是近義詞選擇 | 分開記錄溝通與指定詞結果；接受合理答案、補足真實區分條件，或改做近義詞對比卡 |
| 只會最常見詞義 | 次要詞義是否有獨立語境與評量 | 為真正需要的詞義建立分開提示，不一次加入所有辭典義項 |
| 認得意思但說不出來 | 是否只有目標語到意思方向 | 加入與目標媒介一致的產出卡 |
| 能寫不能聽或說 | 卡片是否只有文字 | 加入音訊提示與口語答案；另做語音能力評量 |
| 背出指定詞卻常用錯場合 | 目標其實是否包含語用與語域 | 加入對象／場合對比；若仍失敗，改用情境判斷或互動方法 |
| 製卡時間大於練習時間 | 是否過度美化、加入太多欄位或查核低價值項目 | 回到最低欄位；優先用可靠現成資源；只精修反覆失敗卡 |

## 12. 維持、升級與停止條件

### 維持目前方法

在延遲測驗中，指定方向的正確率與速度持續改善，複習量可負擔，而且未見語境或目標任務也開始受益時，維持簡單詞卡即可，不必為了增加個人化或 AI 功能而換系統。

### 局部升級

只有觀察到明確缺口時才調整：

- 接收穩定、產出不足：加入產出方向。
- 單一詞義穩定、次要詞義常誤解：加入該詞義的獨立情境提示。
- 卡片答對、搭配仍錯：把完整搭配或句框設為答案。
- 文字穩定、聽辨不足：改用音訊提示。
- 短期答對、延遲失敗：調整間隔、成功標準或重複次數。
- 提示內答對、未見語境失敗：加入變式情境或改用填空、造句與任務練習。

### 停止或換方法

下列情況不應只繼續增加卡片：

- 目標內容已不再重要，或可由工具直接可靠完成。
- 到期複習長期排擠更接近目標的閱讀、聽力、寫作或互動。
- 學習者已能在目標任務穩定使用，卡片只重複已掌握內容。
- 主要瓶頸是篇章理解、語用判斷、即時協商或完整任務整合，而不是詞彙提取。
- 卡片內容無法可靠查核，特別是法律、醫療、行政或其他高後果用語。

## 13. 依任務與個人缺口選擇詞卡的決策支援系統

前面各節分別說明詞卡的目標單位、接收／產出方向、提示形式、排程、評量及操作負擔。本節把這些規則整合成一個<strong>詞卡決策支援系統（flashcard decision-support system）</strong>的研究構想，用來回答：「對這位學習者、這個詞義與這項目標任務，目前最少需要哪些卡片、解說或其他活動？」

這套系統不是新的記憶機制，也不是要求學習者自己逐格操作 9×2 分析。它的價值在於把研究端較完整的分析轉換成少量可執行建議，同時保留第 12 節所說的維持、升級與停止條件。若成熟教材或簡單雙向詞卡已能達標，就不應只因系統能提供更細的分析而增加設定與練習負擔。

### 13.1 定位、適用範圍與非目標

系統從目標內容已通過[材料選擇與準備](../材料選擇與準備.md)的優先判斷後開始，不重新決定所有值得學的單字。它負責把已選定的詞、詞義、搭配或多詞單位，依目標任務與學習者缺口轉成最小練習組合；若詞卡不適合，也必須能建議先解說、改用其他活動或暫不練習。

第一版不應宣稱做到下列事項：

- 替每個詞提供跨學習者通用的單一難度分數；
- 把 Nation 九個面向機械地轉成固定十八張卡；
- 僅憑母語或程度標籤便判定個人的實際缺口；
- 用卡片數量、軟體成熟率或預測分數代替延遲保持、未見語境及目標任務表現；
- 保證 AI 生成的解說、例句、音訊、答案或評分正確；
- 因為可以製卡，就假定詞卡比閱讀、聽力、寫作、互動或直接使用工具更合適。

因此，較準確的名稱是「決策支援」而非「自動課程」：系統整理候選選項、理由與不確定性，最後仍以可靠來源、實際表現及使用者可承受的負擔修正。

### 13.2 輸入與輸出

至少要分開四類輸入，避免把群體常見難點直接當成個人事實：

| 輸入 | 最低內容 | 在決策中的作用 |
|---|---|---|
| **目標任務要求** | 對象與情境、接收／產出、文字／語音、精確度、速度、提示條件、語境範圍、穩定性與錯誤後果 | 決定哪些詞義與 9×2 分析位置真正需要學，以及成功標準 |
| **詞彙項目剖面** | 詞目、目標詞義或構式、發音與詞形、概念邊界、搭配、文法功能、使用限制及可靠來源 | 找出可能需要分卡、解說或其他活動的知識位置 |
| **同母語群體先驗** | 語言配對中常見的形式相似性、概念對應、母語干擾、既有候選卡與來源 | 提供可重用的初始預測，降低每位學習者重新分析的成本 |
| **個人表現資料** | 已知內容、作答方向與媒介、提示、正確與錯誤、反應時間、停頓、最近成功提取、延遲保持、未見語境及任務表現 | 確認或推翻群體先驗，決定實際加入、停用或升級哪些練習 |

輸出不能只有「加入卡片」。每一個目標項目至少允許下列結果：

| 輸出 | 適用情況 |
|---|---|
| **不需建卡** | 已穩定達到目標、項目價值不足、可用簡單替代表達，或現場能由工具可靠承接 |
| **簡譯或基本形式—意義卡** | 母語概念大致等價，任務只需基本辨認或指定形式的初步提取 |
| **簡譯＋關鍵區辨或特定卡型** | 有一項重要詞義邊界、詞性、發音、構式、搭配、語域或媒介缺口需要獨立練習 |
| **先解說，再加入少量可測卡片** | 概念抽象、跨語言邊界不等價，或需多個實例才能建立共同概念 |
| **改用未見語境或其他方法** | 主要目標是語用選擇、長篇理解、自由產出、即時互動或完整任務整合，短卡無法可靠判定成功 |

每項輸出還應附上選擇理由、直接觀察到的缺口、預計成功標準、來源與查核狀態，以及哪些判斷仍只是群體先驗或系統推測。

### 13.3 最小決策流程

系統依下列順序運作；前一步沒有通過時，不因後面能製作精緻卡片而繼續：

1. **確認內容已值得投入**：沿用材料選擇框架，檢查任務相關性、頻率與分布、瓶頸、錯誤後果、替代表達、已有知識、學習負擔及工具可替代程度。
2. **建立任務要求剖面**：指定需要哪個詞義或構式，以及接收／產出、文字／語音、精確度、速度、提示與穩定性；不以「完整學會這個詞」作為模糊目標。
3. **找出個人缺口**：優先使用前測、既有練習及真實任務表現；資料不足時才以同母語群體先驗提出暫定建議，並標示信心不足。
4. **判斷詞卡是否適合**：形式—意義連結、特定詞形與可清楚判分的搭配通常較適合；概念建構、語用、自由產出或完整任務可能只適合局部使用詞卡。
5. **選出最小組合**：依第 5.6 節從簡譯開始，只在任務要求或實際錯誤顯示必要時，增加關鍵區辨、情境、語音、產出、搭配或使用限制卡。
6. **估計並限制負擔**：依第 11 節估計理解、準備、複習、修正與評量成本；若較複雜組合不能合理改善預期成效，退回較簡單方案。
7. **用表現資料更新**：依第 12 節維持、局部升級、停用卡片或改用其他方法；靜態難度標記不能阻止這項更新。

可把流程簡寫為：

> 已選定的目標內容 → 任務需要的知識位置 → 個人尚未掌握的位置 → 詞卡適用性 → 最小卡組或其他活動 → 負擔檢查 → 第 12 節的持續調整

以下用 *physicist*、*content* 與 *grace* 示範同一流程。例子中的任務條件與前測結果都是為了說明決策而設定；換成其他任務或學習者後，輸出也應跟著改變。

**`physicist`：先確認任務是否真的需要文字、語音與產出**

| 步驟 | 判斷與結果 |
|---|---|
| 1. 內容價值 | 假設目標是閱讀英文科普文章，並寫出一句人物身分摘要；*physicist* 在材料中反覆出現且直接影響理解，因此保留。若只在單篇文章偶然出現，而且可當下查詢，就不必直接建卡。 |
| 2. 任務要求 | 閱讀要求看到 *physicist* 後取得「物理學家」；摘要則要求從人物職業概念寫出 *physicist*。目前任務不含聽力或口說，因此不先要求語音辨認與發音產出。 |
| 3. 個人缺口 | 先檢查學習者是否已知道 *physics*，能否在未見句子中認出 *physicist*，以及能否無提示寫出它。若三者都已符合任務標準，輸出是「不需建卡」；不能因系統已有候選卡便重複練習。 |
| 4. 詞卡適用性 | 此處的主要缺口若是形式—意義連結或拼寫，可以用短卡清楚判分；不必先增加長篇概念解說。 |
| 5. 最小組合 | 只缺閱讀辨認時，加入一張文字接收卡；只缺摘要中的書寫提取時，加入一張要求實際輸入完整拼字的產出卡；兩者都缺才使用兩個方向。若之後加入科普 Podcast 任務，再先測聽辨，失敗時才增加音訊接收卡。 |
| 6. 負擔檢查 | 記錄首次理解、建卡及複習時間；如果可靠教材已附詞義與練習，直接使用現成材料可能比另建系統卡更省時。 |
| 7. 後續更新 | 在未見文章中能迅速認出、也能在新摘要中正確寫出後，延長間隔或停用相關卡；若只在原例句答對，先換語境檢查，不立即增加其他面向。 |

**`content`：先拆開任務需要的詞義、詞性、讀音與構式，再逐項前測**

| 步驟 | 判斷與結果 |
|---|---|
| 1. 內容價值 | 假設學習者需要讀、聽並撰寫媒體分析，其中會遇到名詞 *content*「內容」；另有閱讀材料使用形容詞 *content*「滿足的」及 `be content with + 名詞`。兩種用法都與任務相關，因此保留；不相關的辭典義項不納入。 |
| 2. 任務要求 | 名詞義需要文字與語音接收，並在寫作中產出；形容詞義目前只要求閱讀理解及辨認 `content with`，不先要求自由產出。兩者詞性、意義與讀音不同，所以分開建立要求剖面，不能只用一張「content＝內容／滿足」概括。 |
| 3. 個人缺口 | 分別測試：能否從名詞的文字與錄音取得當下意思、能否在媒體分析中寫出名詞，以及能否在未見句子中理解形容詞與 `content with`。某一項答對不能替其他項蓋章。 |
| 4. 詞卡適用性 | 名詞與形容詞的形式—意義連結、兩種讀音及 `content with` 都能設計成主要答案清楚的卡；整篇媒體分析是否自然、論述是否完整，則不能用詞卡判定。 |
| 5. 最小組合 | 假設前測顯示名詞文字接收與寫作已穩定，但聽到名詞時認不出，且形容詞與 `content with` 尚未掌握，便只加入「名詞音訊 → 當下意思」「形容詞語境 → 當下意思」及「辨認 `content with` 的必要構式」三項，不重複已會的文字接收與產出卡。若任務日後要求自行使用形容詞，再另測產出後決定是否加卡。 |
| 6. 負擔檢查 | 估計取得兩種可靠錄音、分開詞義與準備未見句子的成本；若現成學習辭典已能提供核對材料，優先引用而不重複製作。 |
| 7. 後續更新 | 若音訊卡答對但連續語流仍聽不出，先改用含目標詞的自然語流，而不是繼續增加孤立詞重複；若卡片成功但寫作仍誤用詞性或構式，轉入句子改寫或實際寫作回饋。 |

**`grace`：先決定目標是固定構式，還是需要建立抽象概念邊界**

| 步驟 | 判斷與結果 |
|---|---|
| 1. 內容價值 | 先查看實際任務。若目標只是閱讀合約或帳務通知中的 *grace period*，需要的是該多詞單位；若目標是閱讀文學、人物描寫或宗教文本，才可能需要 *grace* 表示優雅、恩惠或其他抽象概念。不能因辭典列出多個詞義便一次全部納入。 |
| 2. 任務要求 | *grace period* 可設定為「看到或聽到完整詞組後理解額外寬限期間」，必要時再要求產出。抽象詞義則要逐一指定文本中的目標概念、典型語境、接收／產出方向及需要區分的近似中文說法。 |
| 3. 個人缺口 | 對固定構式，直接用未見通知測試能否理解；對抽象詞義，先檢查學習者是否只記得一個中文近似詞、能否說明適用與不適用情境，以及是否會把不同詞義混在一起。 |
| 4. 詞卡適用性 | *grace period* 的形式—意義連結可由完整多詞單位卡處理。抽象詞義若尚未建立概念，單張簡譯卡容易把近似翻譯當成完整定義；此時先用已核對解說、正反例與多樣語境建立概念，再決定哪些區辨能轉成卡片。 |
| 5. 最小組合 | 只需 *grace period* 時，先用一張接收卡；任務需要產出且前測失敗時，再加產出方向。若需要某個抽象詞義，保留一張核心形式—意義卡，並只為最影響任務的概念邊界、固定搭配或對比增加卡片；其他詞義暫不加入。 |
| 6. 負擔檢查 | 把閱讀解說、查核例句、製作正反例、日常複習及未見文本評量分開計時。若完整卡組的準備與複習成本高於直接在目標文本中查詢及學習，而且沒有帶來更好的延遲或遷移表現，就退回較簡單方案。 |
| 7. 後續更新 | 固定構式已能在未見通知中理解或使用時，維持或停用相關卡。若抽象詞義在卡片內答對、換到新文本卻仍誤解，瓶頸已不是單純提取，應改用語境比較、閱讀討論或其他更接近目標的活動。 |

### 13.4 同母語群體基準與個人校正

對一群同母語、學習同一目標語的人，最值得共用的是<strong>基準內容層</strong>，包括可靠釋義、常見跨語言概念落差、詞義與構式拆分、候選例句、錄音、卡片模板及來源。這能分攤查找、查核與製作成本，也可提供初次使用時的暫定負擔剖面。

不過，同母語不代表學習負擔相同。程度、其他已知語言、領域知識、接觸經驗、目標任務、媒介及可用準備時間都可能改變實際需要。系統應採「群體先驗 → 任務篩選 → 個人前測或既有證據 → 持續校正」的順序：

- 群體資料只能標成「可能需要注意」或提供預設候選卡，不能直接標成個人已知或未知。
- 個人已在未見語境及目標任務穩定成功時，即使群體資料標成高負擔，也不應強制加入相關卡片。
- 個人反覆失敗但群體基準未預測時，應新增或修改個人的練習，不必先等群體難度標籤更新。
- 多位學習者反覆出現同型缺口後，才考慮把它回寫成更可靠的群體先驗；仍須保留語言對、程度、任務與取樣範圍。

因此，對群體而言，系統的主要價值是建立可重用、可查核的內容基礎設施；對個人而言，主要價值則是刪除不必要內容，並依表現選出符合當下任務的最小組合。

### 13.5 負擔估計與進度安排

卡片數量比詞彙數量更接近「有多少個可分開提取的目標」，但不同卡片並不是等值工作。一張新的抽象概念產出卡、一張已成熟的基本接收卡，以及一張需要播放音訊並人工核對的口語卡，可能需要完全不同的時間。因此，「一天 40 張卡」只有在卡片類型、成熟狀態與實際作答資料相近時，才能作為粗略比較；不能直接視為比「一天 20 個詞」精確的通用負擔單位。

第一版至少應分開估計：

- 新項目的理解與首次學習時間；
- 當日到期複習的預期時間；
- 答錯後核對及再次提取的時間；
- 解說、例句、音訊與答案的準備及查核時間；
- 含糊卡片、錯誤概念及失效材料的修正時間；
- 未見語境與目標任務的低頻評量時間。

主要輸出宜使用**實際或預期總分鐘**，並把新卡、到期複習、反覆失敗、卡片維護及外部評量分開報告；卡片數只作牌組規模與進度的輔助資訊。累積個人資料後，可依卡型、方向、媒介、反應時間、失敗率及再次提取次數更新預估，但不把這些資料轉成看似精確、跨學習者通用的難度總分。

### 13.6 第 12 節的優先地位、證據與驗證

本章的靜態分析只產生初始候選建議；第 12 節依實際表現形成的維持、升級與停止條件具有優先地位。兩者不是衝突的規則，而是不同時間點的工作：本章處理「第一次怎麼選」，第 12 節處理「使用之後怎麼改」。

具體來說：

- 簡單詞卡已改善指定方向，而且複習量可負擔時，維持原方案，不因系統另有高階卡型便自動升級。
- 只有在接收／產出、詞義、搭配、語音、延遲保持或未見語境出現明確缺口時，才加入相應卡片或其他活動。
- 卡片已排擠更接近目標的活動、學習者已穩定達標，或瓶頸已轉為篇章、語用、互動與完整任務整合時，系統必須能停用卡片或建議換方法。
- 群體先驗、九面向分析與 AI 建議都不能覆蓋個人延遲保持、未見語境及目標任務表現。

目前外部研究支持有意詞彙學習、提取、間隔、回饋，以及依不同詞彙知識面向選擇練習的若干組成原則；但尚未直接證明本章這套完整推薦流程優於一般詞卡、成熟教材或其他簡便方案。因此，整套系統應標為**理論與間接證據支持、但完整方法尚待驗證的專案操作假說**，不因演算法或 AI 介入而提高證據等級。

未來若以明確語言配對、任務與學習者進行個案或群體比較，至少應檢查：

- 是否減少不必要的詞義、方向與卡片；
- 準備、查核、首次理解、複習、修正及評量的總時間；
- 原卡的延遲保持、提示撤除及未見語境遷移；
- 目標任務的正確率、速度、穩定性及失敗類型；
- 系統建議是否錯加低價值卡片、漏掉重要缺口，或把應改用其他方法的問題繼續留在詞卡中；
- 相對成熟教材或簡單詞卡基準，增加的成效是否足以抵銷設定、查核及持續操作負擔。

在出現實際原型需求前，本章只規定決策邏輯、輸入輸出、證據邊界與評量方式，不預先建立介面、資料庫欄位、演算法權重或完整產品流程。後續個案檢查依 [PROJECT.md](../PROJECT.md) 第 4.4 節執行，本文件不另建重複核取方塊。

### 13.7 來源限定、AI 製卡與人工責任分配

第 13.1–13.6 節把任務要求、詞彙剖面、個人缺口、卡片選擇、負擔及後續調整拆成可依序處理的步驟，因此目前的 AI 可以承接大量候選內容擷取、初步分類與卡片草擬工作。較合理的預期不是固定保留某一種人機分工，而是把個別學習者的日常負擔，盡可能從「親自查找、分析並製作每張卡」轉成「確認目標與重要內容、選擇候選卡、回報含糊或錯誤，以及完成低頻的遷移檢查」。這項負擔轉移是依本章流程形成的專案推論；目前沒有直接研究能量化一般學習者可省下多少製卡與查核時間，也不能假定今天需要人工逐張核對的工作，未來仍應用相同方式分配。

這種分工要成立，至少需要可靠的共用內容層：用當時經驗證的查核流程，核對可重用的詞義、構式、錄音、卡片模板與來源；系統再依個人任務與表現選出候選組合。查核流程可以包含教師、編輯者、可靠參考資料、規則檢查、另一個模型或抽樣稽核，但任何一項都不能只因掛上「人工」或「AI」標籤便視為正確。若完全由自學者逐張判斷抽象詞義、語域與自由產出答案，學習者可能尚未具備足以辨認錯誤的語言能力；反過來說，若 AI 在某項語言判斷已穩定優於審查者，要求能力較弱的人逐張修改也可能引入新錯誤。兩種情況都不能把「有人確認」當成充分品質控制。

#### 13.7.1 限定已知文本能降低什麼風險

若先由人選定與學習目標相關、來源可靠且可合法使用的文本，再限定 AI 只能從其中擷取候選項，可以降低三類明顯風險：

- 選入目標材料沒有出現、實際任務不需要的詞義或構式；
- 捏造原文不存在的用法、例句或說話情境；
- 無法追查某張卡為何被選入，以及它對應文本中的哪一處。

限定文本也能讓每張候選卡保留原始句段、文件名稱、位置、前後文與選入理由，使人類可直接回到來源核對。教育題目生成研究顯示，輸入內容的整理方式會影響生成品質；Dugan et al.（2022）在特定教科書題目生成實驗中，以人工摘要取代原始篇章後，專家評定可接受的題目比例由 33% 提高到 83%。這項結果支持「縮小並整理輸入可能改善生成」，但不是詞卡系統的直接效果證據，也不能把該數字外推成本系統的預期改善幅度。

不過，「有指定來源」不等於「產出只會包含來源支持的內容」。Stolfo（2024）在檢索增強長篇問答中發現，即使模型取得文件，生成內容仍有相當部分無法由檢索文件或已檢查的訓練資料支持；Joren et al.（2025）也顯示，模型在提供的脈絡不足時，經常選擇產生錯誤答案而不是拒答。因此，限定文本仍可能留下：

- 選錯同形詞、詞性或當下詞義；
- 遺漏否定、反諷、指涉對象、說話者立場及跨句前後文；
- 把偶然共現誤判為固定搭配；
- 產生過寬、過窄或不自然的翻譯與概念解說；
- 產生有多個合理答案、無法作答或答案不一致的題目；
- 由本身錯誤、過時或不具代表性的來源建立卡片。

Fu et al.（2024）對自動問題生成的多面向評估也指出，生成題目常有清楚度、事實一致性、可作答性及答案一致性問題，既有自動指標和人工判斷也未必一致。因此，來源限定應被視為降低捏造與提高可追溯性的措施，不是消除錯誤的保證。

#### 13.7.2 抽取優先、生成分級

第一版不直接要求 AI「讀完文本後製作完整卡組」，而依離原始來源的距離分成三層：

| 層級 | AI 可以做的工作 | 主要放行條件 |
|---|---|---|
| **A．來源抽取卡** | 保留原句或音訊片段、標示目標形式、建立挖空或原文定位，不新增原文沒有的語言事實 | 以可重現的來源比對確認擷取範圍、目標詞、前後文與答案是否完整；另檢查題目是否值得學且能清楚作答，不因直接來自原文便自動放行 |
| **B．來源支持的轉換卡** | 加入簡譯、當下詞義標籤、詞義或構式拆分、接收／產出反轉及必要說明 | 由經校準的工具或人員，配合可靠辭典、語料或教材核對翻譯、詞義、搭配、發音、語域及可接受答案；原文只能證明該形式在此處出現，未必能單獨證明完整定義 |
| **C．新情境與遷移卡** | 生成原文沒有的新例句、正反例、近義詞對比、干擾選項或新任務提示 | 以獨立於原生成步驟的程序檢查自然度、來源支持、答案唯一性、難度、是否仍測相同詞義，以及是否洩漏答案；高後果內容須另檢查重大錯誤，不能只靠原生成模型自評通過 |

系統預設先使用 A；只有 A 無法滿足目標時才進入 B，需要檢查跨語境遷移時才使用 C。若來源與已核對參考資料不足以支持某個詞義、構式、答案或評分標準，輸出應是「資料不足，暫不製卡／請求補充來源」，而不是用模型既有知識補成看似完整的答案。Joren et al.（2025）的選擇性生成結果支持把脈絡充分性與拒答機制列入系統設計，但尚未直接驗證這套詞卡分級。

#### 13.7.3 每個欄位保留來源與生成狀態

同一張卡可能同時包含原文、辭典資料與 AI 新增內容，不能只用「AI 製作」概括。來源狀態、經過何種查核與是否准予使用也必須分開；「曾由人看過」不等於已證明比 AI 原稿好。最低可追溯紀錄應在第 8 節要求之外，為重要欄位標示：

| 狀態 | 意義 |
|---|---|
| `source-extracted` | 文字或音訊直接取自已核准來源，保留文件、位置與必要前後文 |
| `reference-verified` | 詞義、發音、搭配、語域或其他資訊已由指定可靠參考來源核對，並記錄核對方法與版本 |
| `AI-generated` | 翻譯、解說、例句、題目、干擾選項或評分標準由 AI 新增，尚未因語句流暢而視為正確 |
| `human-reviewed` | 人員已依指定規準核對特定版本與用途；此狀態只記錄審查行為，不自行證明審查改善了品質 |
| `evaluation-passed` | 特定版本已通過當時指定的自動檢查、抽樣稽核或人工評量；須保留評量方法、適用範圍、日期與模型／流程版本 |

系統還應分開保存「來源支持哪一項主張」。原始文本可以支持「這個詞在此句以此形式出現」，學習辭典可能支持「此處詞義與讀音」，個人表現則支持「這位學習者在指定提示下成功或失敗」；三者不能互相代替。只有當卡片主要答案所需的來源都存在，才進入供學習者選擇的候選卡組。

#### 13.7.4 AI、內容維護者與個人學習者的最低責任

| 角色 | 適合承接的工作 | 不應單獨承擔的判斷 |
|---|---|---|
| **AI 系統** | 從核准文本擷取候選項與來源位置、提出任務相關性與 9×2 映射、產生分級候選卡、標記不確定性、估計負擔及依表現提出調整 | 不以流暢度自證詞義、自然度、答案唯一性或高後果內容正確，也不在資料不足時默默補寫 |
| **教師、編輯者或內容維護者** | 設定目標、來源與放行規準，核對自己經校準後確實能改善的欄位，處理抽象概念、語域、罕見用法、群體常見錯誤及高後果例外 | 不因職稱、年資或語言程度便假定審查必有正效益；不以一小群人的結果建立跨程度、跨任務通用難度，也不把一次核對永久套用到後續修改版本 |
| **個人學習者** | 設定或確認目標、選擇候選內容與卡片、回報「已會／不需要／答案含糊／解釋不對」，完成練習及低頻的未見語境與任務檢查 | 不應被要求獨自證明自己尚未掌握的細微詞義、搭配與語域解釋是否正確 |

在共用內容已通過當時有效的查核、任務風險低且卡片主要為 A 或已核對的 B 層時，個人學習者的日常工作可以主要縮減為確認目標與候選內容、選擇卡片、正常練習及回報例外。C 層、新的抽象詞義、自由產出與高後果內容需要較嚴格的獨立評量，但不預先規定必須由某種職稱或固定 CEFR 程度的人逐張核准。語言程度、教學經驗與編輯訓練可以作為初步資格線索，最終仍須看該人員在指定語言配對、卡型與錯誤類別上，是否實際改善 AI 原稿。

#### 13.7.5 以版本化校準決定是否保留人工審查

人工介入不能只和「人類單獨製作」比較，還要和 AI 單獨產出的當期基準比較。Vaccaro、Almaatouq 與 Malone（2024）彙整 106 個人機協作實驗後發現，人機組合平均優於人類單獨工作，卻低於人類或 AI 中表現較好的一方；當 AI 單獨表現高於人類時，人機組合相對 AI 單獨使用反而常有損失。這不是詞卡審查的直接證據，卻足以反對「加上人工核准必然提高品質」的假設。Zhou et al.（2024）也顯示，模型能力提高時，仍可能產生表面合理而人類不易察覺的錯誤，因此同樣不能反向假定「模型更強就不需任何外部檢查」。

對每個重要的語言配對、卡片層級與放行流程，宜用代表性材料比較下列三種條件；若某一方無法在不使用另一方的情況下完成，可以說明原因並只比較可行條件：

1. AI 依指定來源與規則單獨產出；
2. 人員不先看 AI 答案而獨立判斷或製作；
3. 人員審查 AI 產出後形成最終版本。

評量時不把三種條件中的任何一種預設為正確答案；依欄位使用可靠外部來源、未參與該項產生或審查的合格評定者、可重現的自動檢查，或實際任務結果。若評量者能看出材料來自哪一種條件而可能受影響，盡可能採盲評；若目前沒有可信的判準，就保留不確定性，不以三方彼此同意代替正確性。

比較時至少分開記錄來源定位、詞義與形式正確性、自然度、答案範圍與可作答性、任務和學習者適配、重大錯誤、審查誤改，以及總時間。材料品質仍不能代替延遲保持、未見語境與目標任務表現；若要主張較好的卡片實際改善學習，仍須另外評量學習結果。

人工逐張審查只在第三種條件相對 AI 單獨產出有足夠淨效益時保留。若人員能改善任務適配，卻不能穩定改善詞義或語言形式，便只把目標設定、來源選擇、例外處理與學習成效判斷交給人，不授權其改寫相應語言欄位。若人工審查沒有淨效益，可以改用抽樣稽核、只處理系統標記的不確定項目，或在低風險範圍直接使用已通過驗證的流程；若某類罕見錯誤的後果很高，即使平均品質差異很小，仍可為該錯誤保留專家檢查。

模型、提示、檢索或來源限制、卡片模板、語言配對、目標任務或評分規則有實質改變時，先重測受影響的環節，不把舊版本結果自動外推，也不要求未受影響的部分全面重做。這使本節的 A／B／C 分級、來源追溯與成效評量可以保留，而人類角色能隨能力比較結果，從逐張語言糾錯轉向目標、風險、脈絡、抽樣稽核及真實學習成效管理。實際比較與重新校準依 [PROJECT.md](../PROJECT.md) 第 4.4 節執行。

## 14. 第一版卡片範例

### 14.1 接收：指定詞義

| 欄位 | 內容 |
|---|---|
| 目標 | `LX-R`；理解 *break* 在法律語境中的意思 |
| 正面 | *Companies that break the law may face penalties.* |
| 作答 | 說明 *break the law* 的意思 |
| 背面 | 違反法律；*break the law* 是一個常見搭配 |
| 不算成功 | 只回答最常見的「打破」 |

### 14.2 產出：搭配

| 欄位 | 內容 |
|---|---|
| 目標 | `LX-P`＋`LX-P-T`；在受控句中為 *decision* 提取正確的動詞搭配 |
| 正面 | 搭配填空；從 *make*、*do* 選一個：*The committee must ______ a decision by Friday.* |
| 作答 | *make* |
| 背面 | *make a decision*；完整句：*The committee must make a decision by Friday.* |
| 不算成功 | 選 *do*；翻面後才認出 *make* |

### 14.3 聽辨：語音到意思

| 欄位 | 內容 |
|---|---|
| 目標 | `PH-R` 支援 `LX-R`；從連續語流辨認已知詞組 |
| 正面 | 一段包含 *take a break* 的已核對音訊，不先顯示文字 |
| 作答 | 說出聽到的詞組及當下意思 |
| 背面 | 音訊重播＋文字 *take a break*＋「休息一下」 |
| 不算成功 | 只在看到文字後才認得 |

### 14.4 難以一對一翻譯的詞義卡家族

以下示範如何把第 3.4 節落實成卡片。詞義、構式與發音已參照學習辭典核對（Cambridge Dictionary, n.d.），但卡片提示與判分方式是本文件的設計示例，不代表辭典或直接比較研究推薦此一格式。實際使用時只保留服務目標任務的卡，不要求把整個示範家族全部加入牌組。

**`privilege`：真正需要分開的詞義與立場**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 接收 P1 | *It was a privilege to work with her.* | 難得而值得珍惜的機會；此處接近「榮幸」，語氣正面且有禮。辨認出 `a privilege to + V`，不能只答「特權」 |
| 接收 P2 | *Healthcare should be a right, not a privilege.* | 只有部分人才能享有的特殊權利或好處；此處與普遍權利對比，帶批判意味，不能答「榮幸」 |
| 接收 P3 | *He had never examined the privilege that came with his social position.* | 身分或群體位置帶來、本人可能視為理所當然的優勢；屬社會分析用法 |
| 產出 P1 | 你要正式表達「能與她共事是難得而值得珍惜的機會」：*It was a ______ to work with her.* | 指定詞為 *privilege*；*honor* 若在情境中自然，可記為溝通成功但指定詞未提取，不把整句判成語言錯誤 |

詞目總覽把 P1–P3 連回同一詞形，但每張卡分開計分。若學習者目前只需理解社會議題文本，可以只建立 P2、P3 的接收卡，不必因辭典列出 P1 就一併學習。

**`intimate`：詞義、詞性與發音共同決定拆卡**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 接收 I1 | *They remained intimate friends for many years.* | 關係非常親近、彼此熟悉；此處為形容詞，不直接等同所有涉及性關係的用法 |
| 接收 I2 | *She has an intimate knowledge of the legal system.* | 了解得深入而詳細，不是「感情親密」 |
| 接收 I3 | *He intimated that further changes were coming.* | 動詞，表示沒有明說而間接暗示；並辨認 `intimate that + 子句` |
| 語音 I3 | 播放動詞 *intimate*，不先顯示文字 | 辨認為動詞 /ˈɪn.tə.meɪt/；形容詞／名詞則為 /ˈɪn.tə.mət/（此處以美式讀音示意）。只會其中一個讀音不代表另一詞性也會 |

小而私密的場所、委婉指涉性關係等用法，只有在目標材料或任務確實需要時才加入；不能用一張「親密的」翻譯卡宣稱全部掌握。

**`cope`：中文換詞不一定需要拆成不同詞義**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 接收 C1 | *How is she coping after the loss?* | 在困難與情緒壓力下設法承受、處理下去；中文可依句子說「撐得如何」「是否應付得來」，不要求唯一譯詞 |
| 接收 C2 | *He found it difficult to cope with the workload.* | 同一核心意思；另辨認 `cope with + 困難事物`。不因中文較自然地翻成「應付工作量」便另立新詞義 |
| 產出 C2 | 你要用本卡指定表達說某人在壓力下難以承受工作量：*He found it difficult to ______ the workload.* | 填入 *cope with*；若只寫 *cope*，便漏掉此構式需要的 *with*。*handle* 等表達可另記為溝通上合理，但不代表已提取本卡的指定構式 |

這個家族的重點不是收集「應付、承受、撐住」三個中文答案，而是保持共同語意核心，再用不同語境檢查是否真正理解。

**`ambiguous`：核心詞義與語用判斷分開**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 接收 A1 | *The wording of the agreement is ambiguous.* | 文字容許兩種以上的合理解讀；本句沒有提供足夠證據判定作者是否故意 |
| 對比 A2 | 甲：一句話可解讀成兩種意思。乙：說明太籠統，缺少必要細節。哪一個優先對應 *ambiguous*？ | 甲；乙較接近 *vague*。這張卡只練概念區分，不等於已能在自由寫作中產出兩詞 |
| 產出 A1 | 合約的一句話可作兩種解讀，因而可能造成爭議：*The wording is ______.* | 指定詞為 *ambiguous*；若使用其他自然表達，另記溝通正確性與指定詞提取結果 |

**`wit`：單數核心義、複數能力與固定表達分開**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 接收 W1 | *Her speech was full of warmth and wit.* | 以聰明、幽默的語言表達產生的機智；不能只泛答「智力」 |
| 接收 W2 | *She survived by relying on her wits.* | 複數 *wits* 指迅速思考與應變的能力，不要求帶幽默 |
| 構式 W3 | 情境：已經想不到任何辦法，急得不知所措。提取完整表達 | *be at one's wits' end*；只答 *wit* 不算完成多詞單位 |

這些示範同時顯示：同一詞目可以只建立接收卡，也可以依任務加入產出、語音或構式卡；卡片數量由能力需求決定，不由辭典義項數量決定。

### 14.5 從九個面向的缺口選擇卡片

以下例子示範第 4.4 節的選擇方式。它們不是要求同一位學習者全部練習，而是分別從觀察到的缺口出發，選擇一張最低可行的卡。例句與判分方式是操作示意，不代表這些格式已被直接比較研究證明為各面向的最佳做法。

**同一產出目標依媒介分開記錄**

| 觀察到的缺口 | 正面與作答 | 主要判定 | 不能宣稱 |
|---|---|---|---|
| 能說出 *break the law*，但常拼錯 | 「違反法律；使用指定搭配」；要求實際鍵入或手寫完整表達 | 是否提取 *break the law*，以及書寫形式是否正確；兩者可分開記錄 | 不能因拼對就宣稱發音正確 |
| 看得懂 *break the law*，但口說時想不起來或說不清楚 | 同一意圖，但要求實際說出完整表達，再核對可靠錄音或由能判斷者檢查 | 指定搭配是否提取，以及口語形式是否可理解；兩者可分開記錄 | 不能因說對就宣稱能拼寫 |
| 只在看到文字時認得 | 播放含 *break the law* 的未顯示文字音訊，要求指出詞組與當下意思 | 口語形式辨認及語音到意義的連結 | 不能直接外推到自己的發音產出 |

**詞的組成部分與文法功能**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 不規則複數 | `one child → two ______` | *children*；主要檢查指定複數詞形。若只需閱讀辨認，可改為看到 *children* 後判斷其基本詞與數量，不必一律要求產出 |
| 不規則時態 | 「昨天她打破了杯子」：*Yesterday she ______ the cup.* | *broke*；這一反應同時涉及 *break* 的意義、過去式、動詞後直接接物品的用法與拼字。若答成 *breaked*，主要缺口在不規則詞形，不應籠統記成整個詞都不會 |
| 字首／字尾組詞 | 「指定使用 `un- + break + -able` 表達『不能被打破的』」 | *unbreakable*，並能在背面核對三個部分的功能。這種用字首或字尾形成相關詞的方式稱為派生構詞（derivation）。*indestructible* 可是情境中的合理說法，但不代表已提取本卡指定構詞 |
| 動詞後接形式 | 「使用 *avoid* 完成：She avoided ______ the question.」 | *answering*；主要目標是 `avoid + V-ing`。若只靠選項答對，只能證明能辨認；要檢查產出，正面不先提供 *answering* |

**概念邊界、聯想與近義詞選擇**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 概念對比 | 「玻璃仍完整，但出現一條細裂痕。優先選 *break*、*smash* 或 *crack*？」 | *crack*；學習者應能指出它與泛稱破壞的 *break*、強調用力打碎的 *smash* 之差別。選對只顯示在這組選項中的接收判斷 |
| 產出檢查 | 「昨天玻璃沒有碎開，只出現一條細裂痕」；不顯示候選詞，要求完成 *The glass ______ yesterday.* | 提取 *cracked*；另記拼字與過去式詞形是否正確。若使用其他自然說法，依第 6.2 節分開記錄溝通成功與指定詞提取 |
| 大類與具體成員 | 「*rose* 和 *tulip* 都屬於哪個較大的類別？」 | *flower*；*flower* 是較大的類別，*rose* 和 *tulip* 是其中的具體成員。這張卡練詞語間的分類關係，不等於已能描述各種花的外觀或在自由表達中主動使用全部詞彙 |

**搭配與使用限制**

| 卡片 | 正面 | 主要答案與判定 |
|---|---|---|
| 搭配產出 | 「犯錯」：*Everyone can ______ a mistake.* | *make*；*do a mistake* 不符合一般英語搭配。若目標只是在閱讀中辨認 *make a mistake*，可改成接收卡，不必強制產出 |
| 場合／正式度接收 | 「朋友約看電影」與「正式行政公告」兩個情境中，哪一個較可能刻意使用 *commence* 而非一般的 *start*？ | 正式行政公告；這只檢查語域，也就是用語是否符合場合與正式度，不表示 *start* 在正式公告中必然錯誤，也不證明學習者能自行產出 *commence* |
| 場合／正式度產出 | 「把 *The ceremony starts at nine.* 改成刻意較正式的公告語氣，並指定使用另一個動詞」 | *The ceremony commences at nine.*；主要檢查能否依要求提取較正式選項。真實寫作仍須看整篇文字、對象與機構慣例，不能由一張卡判定整體用語是否符合場合 |
| 特定場合 | 「朋友遭逢喪親，你要正式表達哀悼；提取本卡指定名詞」 | *condolences*，如 *Please accept my condolences.*；不能把它當成所有『遺憾、同情』情境的通用替代詞 |

這組例子也說明，拆卡的依據不是「九個格子都要有一張」，而是同一詞彙知識在不同媒介、方向或使用條件下是否存在可獨立診斷的缺口。若學習者已能在未見情境及目標任務中穩定表現，就不必為了框架完整而繼續增加卡片。
