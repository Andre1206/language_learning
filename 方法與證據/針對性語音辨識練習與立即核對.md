# 針對性語音辨識練習與立即核對

最後更新：2026-11-18

> 本文件補充[練習方法與證據框架](../練習方法與證據框架.md)第 10.5 節，詳細說明如何把已觀察到的語音辨識問題，轉成可作答、可核對並能檢查遷移的低負擔練習。主要讀者是對語言學習有興趣的台灣高中生；例子以中文母語者學英語為主，但分析方式可套用到其他語言配對。語音學／音韻學、音素／音位、音段／韻律、連續語流及不同知覺任務的定義與分界，見[語音與聽辨知識框架](../語音與聽辨知識框架.md)。

---

## 0. 先說結論

這個方法不是籠統地「多聽」，而是先選定一個聽力瓶頸，例如把英語 *light* 聽成 *right*、漏掉弱讀的功能詞，或無法從連續語流中切出已知單字；學習者先聽並作答，再立即核對可靠答案、重聽錯項，最後用未練過的材料檢查是否真的學會辨識。

最低可行版本只需要：

1. 一個已觀察到、而且會影響目標任務的語音辨識問題。
2. 少量能凸顯該問題的錄音，以及可核對的圖片、情境、文字、分類或其他答案形式。
3. 學習者先作答，再看答案；答錯後能重新聽出關鍵線索。
4. 至少一組未練過的詞項、句子或錄音，用來區分學會辨識與記住原題。

最初可以固定同一位說話者與錄音條件。只有當目標任務需要理解不同說話者，或固定說話者下已穩定但換人就失敗時，才增加說話者、口音或錄音條件的變異。「多說話者」是重要的<strong>泛化（generalization）</strong>選項，也就是用來檢查能力能否延伸到未練過的材料；它不是所有學習者一開始都必須承受的負擔。

研究支持第二語言語音知覺訓練及高變異語音訓練（high-variability phonetic training, HVPT）的整體方向，也支持把作答、矯正回饋（corrective feedback）與未練過的材料評量列為重要組件；但這些研究主要處理音段（segmental，例如母音與子音）、音節結構、聲調或重音等語音目標，不能直接證明短音訊練習會改善所有長篇聽力問題。句子或段落聽不懂時，還須檢查詞彙、文法、篇章、語用與理解監控。

## 1. 方法定義與範圍

### 1.1 方法 ID 與核心流程

| 欄位 | 本方法的紀錄 |
|---|---|
| 方法 ID／名稱 | `PM-PH-ID-01` 針對性語音辨識練習與立即核對 |
| 主要服務對象 | `PH-R`：從語流辨認語音形式、詞界、重音、語調與任務所需的重要變異 |
| 優先連結任務 | `A-EX-02`、`D-LS-01`，並可支援含即時聽解的 Q3 任務 |
| 主要學習條件 | `LC-LFL` 語言形式導向學習；加長語境後可逐步接回 `LC-MFI` 意義導向輸入 |
| 核心實作機制 | `M-CF` 矯正回饋；明確說明、重複與材料變異是否加入，依缺口另記 |
| 主要直接結果 | 對指定語音目標的辨認更準確、較快，並能遷移到預先指定的未見材料 |
| 主要外推限制 | 短音訊辨識不能直接代表長篇理解、語用推論、口語產出或完整目標任務成功 |

本文件所稱**語音辨識**，是學習者從實際聲音中辨認出任務所需的語言形式或語音類別。例如聽出兩個音不相同、判斷聽到哪個詞、切出詞界，或辨認重音與語調所標示的形式差異。它不是只看規則說明，也不是只跟讀而不檢查自己原先聽到了什麼。

核心流程是：

> 指定辨識目標 → 先聽並作答 → 立即核對 → 定位錯誤線索 → 重聽或重新作答 → 用未見材料檢查

### 1.2 什麼不算本方法

以下活動可能有其他用途，但不包含本方法的完整核心：

- 播放大量影音，卻沒有指定要辨認什麼，也沒有可核對的作答。
- 一開始就同時看完整字幕，使學習者不必從聲音辨認形式。
- 只聽教師解說發音規則，沒有實際辨識題與回饋。
- 只模仿或跟讀，卻沒有分開評量接收端是否真的聽得出差異。
- 反覆播放同一題直到背出答案，卻沒有未見材料。
- 只做整段內容問答，無法判斷錯誤究竟來自語音、詞彙、文法或篇章理解。

### 1.3 與 HVPT 的關係

典型 HVPT 會使用多位說話者、多種語音環境及逐題矯正回饋，讓學習者練習辨識目標語音。它是本方法中證據相對充分的一個高變異變體，不等於本文件所有低負擔版本。

本文件容許先用單一說話者與少量材料隔離問題，再依目標任務和實際失敗逐步增加變異。這項安排符合本專案「先採夠好而簡便的方案，發現缺口後再升級」的原則；但單一說話者起步是否比直接採 HVPT 更有效，現有證據不足以作普遍判斷，應視為需由個案表現校正的操作選擇，不宣稱是研究已證明的固定順序。

## 2. 先確認問題是否適合用本方法

一句話或一段話聽不懂，不代表瓶頸一定在語音。第一步不是立刻增加語音題，而是先確認聲音在當下條件中可用：音量、播放設備、網路傳輸、背景噪音、混響或音訊失真是否已遮蔽訊號。若相似困難長期出現在母語、非語言聲音及不同設備或環境，並影響日常功能，便不應自行歸因於第二語言學習；本方法不能篩檢或診斷聽覺或注意力相關狀況，必要時應由合格專業人員評估（National Institute for Health and Care Excellence, 2018）。

確認聲音可用後，再確認學習者是否已掌握目標口語形式及其意思。查核方式應配合學習者的年齡、識字經驗與目標任務：可以用圖片、物件或動作、情境配對、母語解釋、口頭回應，或學習者已熟悉的孤立口語形式；只有在學習者已掌握相關文字，而且閱讀或拼字也是適切提示時，才把逐字稿列為選項。這裡不要求先學會閱讀，才有資格診斷或練習聽辨。

若要進一步區分語音知覺與詞彙問題，可比較學習者能否辨認同一詞的孤立或較清楚口語形式，再比較它進入連續語流後的表現。一次錯答通常不足以判定主要缺口，應比較下列現象：

| 觀察到的現象 | 較可能的主要缺口 | 本方法的角色 |
|---|---|---|
| 母語與目標語在特定設備、噪音或失真條件下都明顯下降 | 聲音可用性、一般聽覺或非語言因素 | 先更換或校正設備與環境；若問題長期跨情境存在，本方法不能取代專業評估 |
| 已能透過圖片、情境、母語解釋、口頭回應或適合該學習者的文字確認詞義，也能辨認較清楚的口語形式，進入原音卻認不出 | `PH-R` 或聲音形式的 `LX-R` | 適合；再定位音位、弱讀、詞界、重音或其他線索 |
| 能聽寫大部分詞，卻不懂整句意思 | `LX-R`、`GR-R` 或 `DC-R` | 不應只增加語音辨識題；轉向相應能力與[聽力策略循環](./聽力策略循環.md) |
| 慢速、清楚錄音能懂，回到未調速的來源原音就大量漏失 | 可能是連續語流辨識、處理速度或詞彙自動化 | 可先用本方法隔離；仍須以來源原速的未見材料檢查 |
| 同一教師能懂，換人就失敗 | 跨說話者泛化不足，也可能是陌生口音 | 適合加入多說話者變體，但材料範圍須對齊目標任務 |
| 每個詞似乎都聽到，卻誤判諷刺、立場或話外之意 | `PR-R`、`DC-R` | 本方法只能處理承載語用訊號的重音或語調部分，不能取代語用練習 |
| 聽得懂但說不清楚或對方聽不懂 | `PH-P` 或其他產出能力 | 另做口語產出與可懂度評量，不能用知覺成績代替 |

若使用逐字稿，它也不是完美診斷：文字會提供標點、詞界與拼字，可能讓原本困難的句子變容易。因此應把「有文字時能確認內容」當作其中一種定位線索，而不是所有學習者的必要前提，也不能單獨證明問題只有語音。能辨認孤立或仔細形式、進入連續語流卻失敗，也只能縮小原因範圍；詞彙熟悉度、語音環境、語速、說話者與上下文仍可能共同影響結果。

## 3. 每次只指定一個可判定的辨識目標

### 3.1 可訓練的目標類型

本方法可處理的目標包括：

- **音段對比**：例如英語 /r/ 與 /l/、日語長短母音。
- **音節與詞形線索**：例如尾音、複輔音或音節數。
- **連續語流**：例如弱讀、連音、同化、省略及詞界。
- **韻律線索**：例如詞重音、句重音、節奏、語調或聲調。
- **任務限定變異**：例如目標地區、專業環境或媒體類型中確實常見，而且會影響辨認的重要發音變異。

內容是否值得學、要從哪些真實來源取樣，以及如何確認語言形式與意思，先依[材料選擇與準備](../材料選擇與準備.md)處理。本文件負責內容選定後的提示、作答、回饋、變異安排與評量。

### 3.2 不把整個口音當成一個練習目標

「聽懂美式英文」「適應關西腔」或「聽懂自然語速」都太大，無法直接設定答案與成功標準。應先找出會改變方法或材料的較小問題，例如：

- 在指定語境中辨認英語弱讀後的功能詞；
- 從來源原速或目標任務所需速度的句子切出已知多詞單位；
- 區分日語長短母音造成的詞義差異；
- 利用句重音判斷哪個資訊受到對比。

若多種問題同時存在，可以分批處理；不能因為都出現在同一段錄音，就假定同一組辨識題能同時解決。

### 3.3 寫出要求剖面

開始前至少記錄：

| 向度 | 要回答的問題 |
|---|---|
| 精確度 | 只需在兩個預先指定的答案中判斷聽到哪一類，例如 `/r/` 或 `/l/`，還是必須在沒有這類二選一提示時辨認完整詞形、詞界或語調功能？ |
| 速度 | 可暫停思考，還是必須跟上播放或在數秒內反應？ |
| 提示條件 | 有選項、可重播、可降速、可看局部文字嗎？目標現場允許哪些？ |
| 語言與語境範圍 | 目標是哪些詞、語音環境、說話者、口音／語言變體、主題與說話風格？ |
| 聲學條件 | 目標設備、距離、壓縮、混響、背景聲與可接受的音訊品質是什麼？ |
| 持續與篇章條件 | 只需辨認單一短句，還是必須長時間聽獨立短句、分段篇章或不中斷的連續篇章？ |
| 穩定性 | 要跨哪些未見詞項、句子、說話者與日期維持？ |

沒有可靠依據時，不自行設定通用正確率門檻；先以目標任務的實際要求及個人基準表現決定是否足夠。

## 4. 最低可行流程

### 4.1 準備

1. 從實際錯誤或簡短前測選出一個辨識目標。
2. 準備少量練習音訊，每題有可靠答案；最初可固定說話者與錄音條件。至少核對語言變體、說話者背景、朗讀／自然對話形式、目標片段的前後音與重音，以及逐字稿或標註是否可信。
3. 記錄音訊是否經過切片、降速、降噪、合成或重新配音，並盡可能保留原速與完整前後文。可以線上播放不等於可以下載、剪輯或重製，製作材料前還須確認來源與授權。
4. 另外保留未練過的錄音實例、詞項、語音環境或句子，不在練習中預先播放，並預先寫明評量究竟換了哪項條件。
5. 決定作答形式及允許的重播次數，避免練習時的提示遠多於目標任務。

#### 4.1.1 不為每個學過的單字都製作詞界題

重要單字應有機會在正常口語與句子中接觸，但這不等於每學一個詞，都要另找片段、切音訊並做正式的詞界練習。詞界切分會整合聲學、音韻、詞彙及語境等多種線索，同一個詞換了前後音、重音、語速或說話者後，難度也可能改變（Mattys, White, and Melhorn, 2005）。若逐詞製作材料，不只準備成本很高，也可能只讓學習者記住少數錄音；目前也沒有直接證據支持把「所有已學單字逐一做詞界切分」當成普遍有效或最省時的做法。

較低負擔的預設做法是：先在自然聆聽、目標任務或少量代表性抽查中找缺口，再決定是否進入正式練習。下列條件越多成立，越值得準備針對性材料：

1. 學習者已能用圖片、意思、情境或較清楚的口語形式確認自己知道該詞，進入連續語流後卻認不出。
2. 困難能在未見錄音或新句子中重現，不只是某次分心或單一劣質錄音。
3. 該形式對目標任務重要，誤聽會改變理解、阻礙後續處理或造成較高後果。
4. 錯誤可整理成會改變材料設計的問題，例如弱讀功能詞、特定前後音中的詞界、詞尾線索或說話者泛化，而不只是籠統的「自然語速太快」。

不必硬等到錯誤累積成「經常發生」才介入。否定、數字、姓名、專業術語或關鍵指令等高後果內容，可以在實際錯誤尚少時先做小規模抽查；高頻功能詞與常見縮減也可用少量代表項目檢查。但抽查仍不等於把全部詞彙逐一建題。若多個詞共同顯示相同模式，練習單位應改成該模式及其變異，例如以 *kind of、out of、a bit of* 等不同詞項檢查弱讀與跨詞連接，而不是只反覆練熟一個片語。

這項選擇規則是根據本專案「先採夠好而簡便的方案，發現缺口後再升級」原則、詞界多線索性質及目前證據邊界形成的<strong>低負擔操作建議</strong>；它不是已有研究比較並證明的固定錯誤次數或介入門檻。開始後仍須用未見材料與目標任務表現判斷是否值得繼續。

#### 4.1.2 自學者的三種材料準備路線

自學者可依準備成本由低到高選擇下列路線，不必一開始便建立大型題庫：

1. **直接使用現成辨識練習**：若資源已涵蓋目標音位、重音或題型，而且能先作答再核對，優先直接使用。此時仍要另找未練材料檢查是否只熟悉網站題目。
2. **從附逐字稿的教材或真實來源取樣**：適合弱讀、詞界及連續語流。先保留原頁面、時間碼與完整前後文；若授權不容許下載或剪輯，就在原網站播放並以時間碼定位，不另存或重新發布片段。
3. **自行錄音或使用可再利用的開放語料**：只有當現成材料缺少必要詞句、說話者或任務條件時才升級。自行錄音宜先固定設備與環境，取得錄音者同意，保留原始檔，並預先封存部分新句或新錄音作未見評量。學習者自己的錄音可以用於產出比較，但若該發音尚未核對，不宜單獨充當知覺題的標準答案。

無論採哪條路線，都可先把材料分成三池：練習材料用於作答與回饋；未見材料用於更換錄音實例、詞項、語音環境或說話者；目標任務材料則回到原速考試、節目、對話或通話條件。不要把同一段較長錄音切成數個高度重疊的片段後，一部分當練習、一部分宣稱為未見測驗。

每個材料項目最低可記錄：來源連結或檔名、時間碼、完整句子、目標片段、正確與可接受答案、說話者及語言變體、朗讀或自然對話、前後音與重音、音訊處理方式、授權，以及所屬材料池。逐字稿主要記錄預定或辨認出的語言形式，不會自動證明目標聲音在該次錄音中如何實現；遇到縮減、省略、聲門化或模糊詞界等問題，若無法可靠核對實際聲音，就應排除該題或尋求熟悉語音分析者複核。

文字轉語音（text-to-speech, TTS）可低成本試做介面或提供經核對的清楚基準，但不應未經檢查便代表自然縮減、指定口音或真實說話者變異。自動語音辨識產生的逐字稿也只能協助搜尋和初步定位，不能擔任細微音位、詞界或縮減題的唯一答案來源。這兩項限制與第 12 節尚待驗證的 AI 能力問題相連；在指定系統、語言變體及材料條件完成直接查核前，不把生成或自動標註當成已放行材料。

### 4.2 每題操作

1. **先聽並作答**：在答案出現前選擇、標記或寫下聽到的形式。
2. **立即核對**：以適合學習者的圖片、情境、正確類別、文字或必要的局部提示呈現答案，不只顯示「錯」。
3. **定位線索**：指出一項或一組在這批材料中經核對、足以協助判斷的聲學或語音線索；不把它寫成任何說話者與語境都適用的唯一線索，也不要求每題都讀完整理論。
4. **重聽錯項**：帶著正確答案重聽，確認現在能把聲音與形式連起來。
5. **稍後重新作答**：把失敗項目混回後續題目，避免只產生看完答案當下的熟悉感。

若學習者答對但理由顯示是猜測，或在兩個選項中排除而非真正辨認，也應標記為不穩定，之後用不同題型或未見材料檢查。

### 4.3 一個練習單位結束後

- 用未練過的內容測一次，不提供剛才的答案與額外提示。
- 分開記錄練習題與未見題的正確率、反應時間及重播次數。
- 若未見內容仍失敗，先檢查目標、答案、提示或材料難度；不要直接大量增加題數。
- 若短例穩定，依目標任務決定是否增加句長、語速、說話者或背景條件。

## 5. 作答、回饋與提示怎麼選

### 5.1 作答形式應對齊目標

| 作答形式 | 適合回答的問題 | 主要限制 |
|---|---|---|
| 同／不同判斷 | 是否聽出兩個刺激有差異 | 不一定知道各自是哪個類別或詞 |
| 圖片、物件、動作或情境選擇 | 能否把口語形式連到已知對象、事件或意思；不要求先會閱讀 | 圖片與情境可能提供額外語意線索，也未必能表示抽象詞或細微語法差異 |
| 二選一或多選一辨認 | 聽到哪個音、詞、重音或語調類別 | 選項可能提供目標現場沒有的提示 |
| 詞界標記或選出聽到的片段 | 能否從連續語流切出形式 | 仍可能受拼字與選項影響 |
| 局部聽寫 | 能否辨認指定位置的完整形式 | 同時受拼字、詞彙與工作記憶影響 |
| 完整句聽寫 | 能否在較長語流中保存並重建形式 | 混入文法、詞彙、記憶與書寫，不能視為純語音測驗 |
| 內容問題 | 能否取得句子或段落意思 | 適合檢查遷移，但難以單獨定位 `PH-R` |

不必永遠使用同一題型，也不必把文字題型視為較高階或必經階段。練習時可先用符合學習者經驗、又容易判定的圖片、情境或其他辨認題建立連結；之後依目標任務撤除選項，改用口頭回應、局部聽寫或內容理解檢查提示依賴。若目標任務不需要閱讀與拼字，就不必以聽寫作為最終成功標準。

### 5.2 回饋至少要能讓學習者重建正確連結

最低回饋包含正確答案及再次播放。若學習者仍聽不出差異，再加入一項最有用的支援，例如：

- 短暫顯示局部文字或詞界；
- 對比兩個容易混淆的例子；
- 標出重音位置或目標片段；
- 暫時降速，但記錄使用的處理方式，之後回到未調速的原音及目標任務所需的速度；
- 提供簡短的發音或聲學線索說明。

支援的目的，是讓學習者重新把聲音與形式連起來；不是把所有答案長期留在畫面上。若某種提示一撤除就完全失敗，應記錄為提示依賴，而不是已掌握。降速、切片與降噪也會改變任務：不同降速技術可能改變音高、時長比例或音質，切片則可能移除原本可用的前後文。因此，處理後音訊與原音應分開記錄，不能只在處理後材料答對便宣稱已能應付原始語流。

### 5.3 立即核對不等於立即顯示答案

學習者必須先作答，才進入回饋。音訊一播放就同步顯示完整字幕，通常把活動變成聲音與文字同時接觸，無法知道學習者是否曾嘗試從聲音辨認。字幕可以在答後用於定位，也可以在最後逐步撤除。

## 6. 如何逐步增加材料變異

材料變異不是越多越好，而是要覆蓋目標任務，又不能在尚未形成基本辨認時造成無法學習的噪音。

### 6.1 分開不同變異與泛化層次

| 泛化層次 | 例子 | 它能排除什麼誤判 |
|---|---|---|
| 未見錄音 | 同一個詞由同一人重新錄製 | 排除只記住某一次錄音的細節 |
| 未見詞項 | 目標音出現在新的詞或句子 | 排除只背熟練過的內容 |
| 未見語音環境 | 目標音換到不同前後音、詞中位置或重音條件 | 排除只學會一種局部環境 |
| 未見說話者 | 未練過的說話者說相同或新的內容 | 檢查表現是否過度依賴已接觸說話者的聲音特徵與個人化語音模式 |
| 未見口音／語言變體 | 新說話者使用目標範圍內另一種系統性發音與韻律形式 | 排除把一種變體誤當成整個語言；只在目標任務確實需要時加入 |
| 未見錄音條件 | 換成目標設備、通話壓縮、混響或背景聲 | 檢查能力能否在指定聲學條件下維持；不能據此單獨判定是語音、注意或聽覺問題 |
| 未見連續語篇或任務 | 新句子、短段落、考題或節目片段 | 檢查是否能在多項能力同時運作時使用 |

這些結果要分開報告；「未見材料」若沒有說明換了什麼，無法判斷成效支持到哪裡。同一個詞由同一人重新錄製，只換了錄音實例；它不能自動證明已能跨詞項、語音環境、說話者、口音或錄音條件理解。

還須分開三種時間與材料關係：

- **知覺適應（perceptual adaptation）**：接觸某位說話者、某種口音或失真後，逐漸調整解讀方式。
- **泛化**：把學到的辨認延伸到未練過的詞項、語音環境、說話者或其他條件。
- **保持**：隔一段時間後仍能辨認。

適應同一批材料不等於已泛化，當下換題成功也不等於能跨時間保持。

### 6.2 何時加入多說話者

優先加入多說話者的情況包括：

- 目標任務本來就會遇到不同人，例如考試錄音、會議、節目或現場服務；
- 學習者在固定說話者與未見內容下已穩定，換人卻明顯下降；
- 目標語音在不同聲音與語音環境中變異很大，單一範例容易形成過窄記憶。

換說話者不只是換口音。即使兩人被歸在相同口音或語言變體內，下列特徵仍可能改變學習者可用的線索：

- **聲音來源與聲道特徵**：慣常基頻與音高範圍、聲道長度所造成的共振峰尺度，以及氣聲、嘎裂聲或粗糙度等音質。
- **時間與韻律習慣**：慣常語速、停頓方式、節奏、重音與語調配置。
- **個人化語音實現**：母音空間、嗓音起始時間（voice onset time, VOT）、縮減、協同發音及清晰度等穩定傾向。
- **暫時狀態**：疲勞、情緒或健康狀況也會改變同一人的聲音；這類狀態變化應與相對穩定的個人模式分開記錄。

這些特徵不會一律造成同等困難；只有當差異改變當前辨識所依賴的線索，或同時增加多項變異時，才較可能使表現下降。錄音設備、距離、壓縮與背景聲則屬錄音條件，不是說話者本身的特徵，即使它們在實際材料中常一起改變（Allen & Miller, 2004; Smith et al., 2005; Kraljic, Samuel, & Brennan, 2008; Lee, Keating, & Kreiman, 2019）。

說話者特定的適應及換人後的處理成本，是語音知覺研究中可重複觀察到的現象；熟悉一位說話者也可能提高辨認效率。不過，這通常表示換人時出現相對變慢或變不準，不等於學習者真的「只能聽懂一個人」，目前也沒有可套用所有外語學習者的盛行率（Mullennix, Pisoni, & Martin, 1989; Magnuson et al., 2021）。因此，本文件以「表現是否過度依賴已接觸說話者」描述要檢查的風險，不把單一說話者練習直接判定為狹窄學習。

不應只因研究中常見 HVPT，就把固定的說話者數量當成所有人的最佳處方。多說話者與單一說話者的比較結果有異質性；較新的統合研究顯示說話者數量還會與呈現方式、訓練量、程度及其他設計因素交互影響（Zhang, Cheng, & Zhang, 2021; Zhang et al., 2025; Uchihara et al., 2025）。因此本文件不設定「一定要六位」之類的通用門檻。

### 6.3 不把所有變異一次加入

若同時換說話者、口音、語速、背景噪音、錄音設備與題型，失敗後很難知道該調整哪一項。較容易解釋的做法是每次只增加一兩項與目標任務有關的變異，並保留共同的比較條件。

## 7. 成效評量

### 7.1 至少分開四種結果

1. **練習內表現**：同一批題目是否逐漸答對。
2. **未見刺激表現**：新錄音、新詞項或新句子能否辨認。
3. **延遲保持**：隔一段時間後是否仍能辨認；間隔依個案目的決定，不宣稱固定天數最佳。
4. **目標任務遷移**：在考試錄音、節目片段或互動中，相關錯誤是否減少。

練習內進步是必要的操作訊號，但最容易受到記題與提示影響。若只有練習題進步，應先判定為材料特定學習，不能直接寫成能力已泛化。

### 7.2 指標應同時包含準確與處理條件

可依目標記錄：

- 辨認正確率或錯誤類型；
- 每題反應時間；
- 重播、降速或字幕使用次數；
- 跨詞項、說話者與日期的穩定性；
- 在較長材料中的關鍵資訊理解與理解延遲；
- 練習、準備、查核與評量所花的總時間。

正確率提高但反應非常慢，未必足以應付直播或一次播放的考試；反應變快但錯誤增加，也不能視為完整改善。

### 7.3 需要時另測持續聆聽、篇章與聲學條件

若目標任務只要求辨認短句，不必為了讓方法看起來完整而加入長篇與噪音。若目標任務需要持續聽講、節目、會議或一次播放的考試，短句辨認穩定後，才以條件式分支檢查能否接回目標情境：

1. **單一短句基準**：先在乾淨、短而獨立的材料中確認局部形式仍能辨認。
2. **獨立短句持續條件**：在較長時段聽許多彼此獨立的短句，主要增加總聆聽時間。
3. **分段與連續篇章**：盡量使用相同內容，分別提供或不提供段落間停頓，以區分額外處理時間與篇章保持、整合和漏聽後恢復。
4. **目標聲學條件**：最後才加入任務需要的噪音、混響、通話壓縮或重播限制；一次只改變少數條件，保留可比較的基準。

除了正確率與反應時間，可依任務比較前段、中段與後段的表現、主觀費力程度及聽後記憶。正確率相同，不代表聆聽努力與後續記憶成本相同（Peelle, 2018; Borghini & Hazan, 2018）；噪音下退步也不能直接解讀成注意力不足，因為噪音可能先遮蔽語音線索並增加口語詞辨認負擔（Scharenborg & van Os, 2019）。若局部形式辨認在各段仍穩定，只有篇章內容或後段表現下降，應轉查詞彙、句法、篇章整合、理解監控、持續注意、疲勞或其他條件，而不是繼續增加語音辨識題。這個分支只用來定位目標任務中的遷移缺口，不能篩檢或診斷注意力障礙。

### 7.4 不用知覺成績代替產出評量

語音知覺訓練有時會伴隨產出改善，但後設分析顯示兩者的改善幅度與關係並不相同（Sakai & Moorman, 2018; Yao et al., 2025）。若目標包含讓別人聽懂自己的發音，必須另以未排練產出、可懂度或目標任務評量 `PH-P`，不能因辨認題進步就推定口說已改善。

### 8.1 完整方法與相近方法的直接證據

|---|---|---|
| Yao et al.（2025） | 綜合第二語言語音知覺、產出及混合訓練；整體支持語音訓練能改善受測語音能力，且結果會受訓練類型與測量方式調節 | 不能證明本文件每個低負擔分支、每種語言配對或完整聽力理解都有相同效果 |
| Uchihara, Karas, and Thomson（2025） | 79 項 HVPT 研究的後設分析，直接支持含說話者與語音環境變異、逐題回饋的知覺訓練，並檢查保持與未見刺激泛化 | 納入定義本來就要求至少兩位說話者，不能用來證明單一說話者起步優於直接採 HVPT；主要集中在音段與韻律目標，不等同長篇理解 |

| Zhang, Cheng, and Zhang（2021） | 系統性回顧與後設分析直接比較說話者變異；顯示多說話者對新說話者泛化有小幅平均優勢，但研究結果異質 | 不能推出固定的最佳說話者數量，也不能據此推定在任何語言配對、語音目標、訓練量與呈現方式下，增加說話者都會帶來額外效益 |
| Zhang et al.（2025） | 比較不同說話者數量及呈現方式的系統性回顧與貝氏網絡後設分析（Bayesian network meta-analysis），顯示數量必須連同呈現格式與暴露量解讀 | 排名結果不能脫離納入研究條件，直接變成所有語言、程度與目標的「最佳人數」 |
| Lee and Lyster（2016） | 小型課堂實驗中，接受語音知覺矯正回饋的組別，在立即、延遲及陌生詞辨認上優於只有教學的組別 | 只處理特定母語群體與英語母音對比，不能單篇外推所有回饋形式與語音目標 |

這些時間可用來說明「相近研究曾在數小時至數十小時內測得局部聽辨變化」，不能直接指定本方法每週或總共應做多久。McAndrews（2019）與 Choe, Lee, and So（2020）都主要整合研究間差異，而非在同一實驗中只改變劑量；學習者應依[練習方法與證據框架](../練習方法與證據框架.md)第 7.4 節，分開記錄主動練習、排程、背景接觸與評量時間，並以未見材料和目標任務判斷是否值得繼續。

下列來源有助於判讀問題或設計材料與評量，但不是本文件完整練習流程的直接效果證據：

| 來源 | 可支持的判斷 | 證據邊界 |
|---|---|---|
| Ernestus et al.（2017） | 特定英語縮減形式及聽者母語的音系限制可能影響 *can／can’t* 等辨認 | 支持特定聽辨困難與材料設計，不證明本文件的回饋、重測與升級流程有效 |

### 8.3 本文件哪些部分仍是合理推論或專案假說

- **合理推論**：練習與評量分開使用已練及未見材料，有助於避免把記題誤當泛化；這也符合現有 HVPT 研究對刺激與說話者泛化的區分。
- **合理推論**：依目標任務逐步增加句長、說話者與提示限制，比完全不記錄材料條件更能判斷適用範圍；但最佳增加順序尚無普遍答案。
- **專案操作假說**：先用單一說話者隔離問題，對部分初學者可能比一開始加入大量變異更低負擔；是否較有效或省時，須與直接採多說話者訓練比較。
- **尚有爭議**：說話者的最佳數量、混合或分組呈現方式，以及學習者程度如何調節變異效果，現有統合結果尚不足以形成單一處方。
- **證據不足**：把音位辨認研究直接外推到詞界、弱讀、自然段落或完整節目理解。這些擴展可用相同操作框架試做，但必須另找直接研究或標為待驗證。

## 9. 操作負擔、常見失敗與調整

### 9.1 應記錄的成本

| 成本 | 包含什麼 | 可觀察紀錄 |
|---|---|---|
| 問題定位 | 找出真正反覆的語音瓶頸 | 診斷時間、需要幾段材料、是否能排除詞彙與文法問題 |
| 材料取得與查核 | 尋找錄音、確認逐字稿、切分片段及答案 | 準備時間、來源、需要人工修正的比例 |
| 練習 | 作答、核對、重聽及再次作答 | 實際分鐘、題數、錯誤與重播次數 |
| 變異準備 | 新詞項、新句子、新說話者及不同條件 | 每增加一層泛化所需的額外時間 |
| 評量 | 未見、延遲及目標任務測量 | 評量準備與執行時間、是否與練習材料重複 |

若為了製作大量完美切片、標音與多說話者錄音，準備時間遠高於實際練習，而且成熟教材已能滿足目標，就應先改用現成資源。

### 9.2 常見失敗模式

| 觀察到的問題 | 先檢查 | 低負擔調整 |
|---|---|---|
| 同一題反覆答對，換題就錯 | 是否背熟錄音或答案位置 | 降低同題重複，提早加入未見詞項或新錄音 |
| 看字幕就懂，撤掉字幕完全聽不出 | 字幕是否長期同時出現 | 改成先作答、答後只顯示局部文字，再撤除重聽 |
| 二選一很好，局部聽寫失敗 | 是否依賴選項排除 | 增加不提供答案形式的題型，並分開檢查拼字影響 |
| 固定教師能懂，換人就失敗 | 目標是否需要跨說話者 | 逐步加入少量目標範圍內的新說話者，不必一次混入所有口音 |
| 短詞辨認穩定，句中仍漏掉 | 語音環境、弱讀／縮減、詞界、處理速度或提示差異 | 先用未見短句確認局部形式，再逐步減少重播；不要立刻把失敗歸因於長篇理解 |
| 短句穩定，聽久或進入篇章後下降 | 是總聆聽時間、篇章整合、聲學條件，還是局部辨認先惡化 | 依第 7.3 節分開比較獨立短句持續、分段／連續篇章及目標聲學條件 |
| 音訊形式大多聽對，仍答錯內容題 | 詞義、句法、篇章或語用 | 停止只加語音題，轉用相應方法或[聽力策略循環](./聽力策略循環.md) |
| 題目太難，幾乎全靠猜 | 目標是否過多、對比是否不清、變異是否一次過大 | 減少同時對比的類別，固定部分條件，先建立可學的差異 |
| 練習耗時卻不影響真實任務 | 目標是否只是容易測量而不重要 | 停用低價值對比，改從實際錯誤重新選目標 |

## 10. 維持、升級與停止條件

### 維持目前方法

若未見內容與延遲測驗持續改善，操作負擔可接受，而且目標任務中的同類誤聽開始減少，就維持簡單版本，不必為了符合 HVPT 名稱而增加不需要的變異。

### 局部升級

- 同一內容的新錄音失敗：增加錄音實例，不急著換口音。
- 新詞項失敗：增加詞項變異；若只在特定前後音、位置或重音失敗，另增加語音環境變異。
- 新說話者失敗且目標需要跨人理解：加入多說話者及適當呈現安排。
- 新口音或錄音條件失敗且目標確實需要：一次增加一項目標範圍內的變體或聲學條件，並保留原條件作比較。
- 有選項時穩定、撤除後失敗：改用局部聽寫、詞界標記或開放作答。
- 短例穩定、持續或連續語篇失敗：依第 7.3 節先分開總聆聽時間、篇章整合與聲學條件；若局部形式仍穩定，轉入[聽力策略循環](./聽力策略循環.md)定位其他能力，不繼續堆疊語音題。
- 即時條件失敗：逐步限制重播與反應時間，但保留準確度監控。

### 停止或換方法

- 主要瓶頸已確定是詞彙、文法、篇章、語用或一般知識，而非聲音辨識。
- 已能在目標任務中穩定辨認，額外題目只重複已掌握內容。
- 目標可由工具直接完成，且學習者沒有制度性、備援性或目標定義性的自行理解需求。
- 音訊、逐字稿或答案無法可靠查核。
- 準備與維護成本長期高於成熟教材，而沒有觀察到相對改善。

## 11. 最小示例：在句中誤判 *can／can’t* 的縮減形式

假設一名中文母語的英語學習者已知道 *I can do it* 與 *I can't do it* 所表達的肯定、否定差異，也能在孤立或較仔細的口語形式中辨認兩詞，但在目標來源的連續語流中經常誤判。這個問題可能同時涉及非重讀 *can* 的弱讀、*can't* 的縮減或聲門化、詞尾音系限制，以及學習者尚未整合多項聲學與語境線索；不能預設只要尋找清楚的 `/t/` 爆破就能判斷，也不能因沒聽到爆破便斷定 `/t/` 已完全省略（Ernestus et al., 2017）。

1. **確認目標價值**：否定誤判會改變句意，且目標考試或互動中確實需要即時辨認。
2. **前測定位**：先確認設備與錄音可用，再比較同一學習者對孤立／仔細形式及一位說話者所說未見句子的表現；用圖片、情境、母語解釋、口頭回應或其他適合該學習者的方式確認肯定、否定及句意不是主要問題。若學習者已識字，也可把逐字稿當作其中一項輔助線索，但不是必要條件或單獨診斷。
3. **核對實際材料**：確認這批錄音中的 *can* 與 *can't* 實際如何實現，保留前後語音環境，記錄可用的線索組合及說話者／口音條件，不把教材規則直接當成每題答案的聲學描述。
4. **最低練習**：每題先聽一句並選擇肯定或否定，再顯示答案與局部文字；需要時提示這批材料中可用的一組線索，重聽目標片段，錯項稍後重新出現。
5. **先測內容泛化**：同一位說話者改說未練過的句子，避免只記住原題；另記語音環境是否改變。
6. **依需求增加變異**：若目標會遇到不同說話者，而且換人明顯下降，再加入少量新說話者；若目標包含特定口音或通話條件，才另外測該項變異，不把任意口音與噪音一次混入。
7. **接回完整任務**：使用未見短對話或考試片段，檢查關鍵否定是否仍被正確理解；若聲音形式已辨認但內容題仍錯，轉查其他能力。只有目標需要持續聆聽時，才再依第 7.3 節加入持續時間或篇章條件。

這個示例的成功證據不是「同一組句子終於全對」，而是未見句子與目標形式下的誤判減少，且不再高度依賴字幕、無限重播或固定說話者。

## 12. 尚未解決的問題

本版仍不能提供下列普遍答案：

- 哪些學習者應先採單一說話者，哪些適合直接進入 HVPT；
- 對特定程度、語言配對與目標，說話者和語音環境各需要多少變異；
- 說話者應分組呈現還是混合呈現；
- 辨認、區辨、局部聽寫與其他題型如何以最低總時間組合；
- 不同局部語音目標需要多少累積練習，以及何時開始出現未見材料與目標任務遷移；
- 立即回饋應顯示多少文字、聲學線索或發音說明；
- 音位與聲調訓練結果能在多大程度上外推到弱讀、詞界、來源原速的連續語流及長篇理解；
- 在正確率、反應時間、主觀費力與聽後記憶之間，哪些低負擔指標最能判斷持續聆聽是否足以達成特定任務；
- AI 語音合成產生的材料能否在指定語言、口音與目標音上可靠代表真實變異；
- 自動語音辨識或模型判分是否足以取代人工查核及未見任務評量。

遇到這些問題時，應把選擇寫成可修改的操作假說，分開記錄材料條件、總時間及未見表現；不能把軟體提供的題目數、口音標籤或自動分數當成已驗證的語音能力。
