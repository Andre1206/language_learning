# 聽力策略循環

最後更新：2026-11-18

> 本文件補充[練習方法與證據框架](../練習方法與證據框架.md)第 10.6 節，詳細說明如何在接近目標的完整聆聽中，依序預測、初聽、標記不確定處、核對、定位問題、撤除輔助再聽，並用未見材料檢查策略是否轉移。主要讀者是對語言學習有興趣的台灣高中生；例子以中文母語者聽英語為主，但流程可套用到其他語言配對。語音、詞彙、篇章、聆聽努力與材料條件的分界，見[語音與聽辨知識框架](../語音與聽辨知識框架.md)。

## 0. 這是什麼方法，適合什麼情況

<strong>聽力策略循環（listening strategy cycle）</strong>是一種<strong>帶有形成性評量與瓶頸定位功能的練習方法</strong>。它先讓學習者在接近目標任務的條件下聆聽，檢查任務所需的聽力部分目前是否達標；若未達標，再利用作答依據、不確定位置、局部重聽與輔助核對，縮小主要瓶頸可能落在哪項能力，據此決定下一步要維持完整聆聽、補練單項能力，還是調整材料與聆聽條件。

它不是只在最後判定「會或不會」的<strong>總結性評量（summative assessment）</strong>。循環中的檢查結果會立即改變後續練習，因此屬於<strong>形成性評量（formative assessment）</strong>：評量是為了促進與調整學習，而不是只產生一個分數。它也不是單純的診斷表；完成核對後，學習者還要撤除輔助重聽，並用未見材料檢查修正是否轉移。

本方法特別適合下列情況：

- 目標要求學習者自行聽懂，例如檢定聽解，或不依賴翻譯字幕理解指定影劇、Podcast、直播與歌曲。
- 學習者只知道內容題答錯或「跟不上」，尚不清楚主要問題在語音、詞彙、句法、篇章、語用、理解監控，還是材料與聆聽條件。
- 短句能懂，持續聆聽、進入篇章、限制重播、換說話者或改變聲學條件後卻失去主線。
- 有可靠答案、逐字稿或其他查核方式，也能另備未見材料，避免把記住原音檔當成學會。

若簡單的未見聆聽與答後核對已足以達標，就不必每次做完整循環；若已確定是一個可重複的語音辨認問題，則可直接轉入[針對性語音辨識練習](./針對性語音辨識練習與立即核對.md)。本方法所找出的「主要瓶頸」只是下一步最值得檢查的工作假說，不是由一次錯答確定的單一原因；仍須靠重複型態、條件比較與未見材料修正判斷。

## 1. 方法定義與範圍

### 1.1 方法 ID 與核心流程

| 欄位 | 本方法的紀錄 |
|---|---|
| 方法 ID／名稱 | `PM-LS-MON-01` 聽力策略循環 |
| 主要服務對象 | `ST-MON`：監控理解的不確定性、定位可能錯誤、選擇查核方式並判斷接受、重做或轉向 |
| 支援服務對象 | 依實際內容整合 `PH-R`、`LX-R`、`GR-R`、`DC-R` 與 `PR-R` |
| 優先連結任務 | `A-EX-02`、`D-LS-01`；其他需要獨立聽解與理解監控的 Q3 任務可依條件採用 |
| 主要學習條件 | 初聽與最後重聽是 `LC-MFI` 意義導向輸入；中間定位與核對階段轉入 `LC-LFL` 語言形式導向學習 |
| 核心實作機制 | `M-EXPLICIT` 明確說明與對比、`M-CF` 矯正回饋、`M-TASK-REPEAT` 同一材料重聽；三者的既有機制證據不能取代完整循環的直接證據 |
| 主要直接結果 | 在未見音檔中更準確地監控理解、定位失敗層次、選擇必要查核，並改善與目標任務相符的聽解表現 |
| 主要外推限制 | 同一音檔重聽變好不等於已遷移；自述用了策略不等於理解改善；本方法不能取代不足的語音、詞彙、句法、篇章或語用知識 |
| AI 能力快照 | 核心方法不依賴 AI，因此不適用；若另用 AI 轉錄、切片、出題或判分，須依 `PROJECT.md` 第 1.3 節另記工具快照，且工具輸出不是學習成效證據 |

核心流程是：

> 對齊目標條件 → 有限預測 → 無輔助初聽 → 作答並標記依據與不確定處 → 只用必要輔助核對 → 定位失敗層次 → 撤除輔助再聽 → 決定維持、轉練或升級 → 用未見材料檢查

### 1.2 研究中的完整後設認知教學循環

本方法最接近的既有做法是<strong>後設認知教學循環（metacognitive pedagogical sequence）</strong>。完整課堂版本不只是學習者自己重聽一次，而是由教師跨多次聽力活動，引導學習者反覆規劃、監控、驗證、解決問題與評估。常見流程可整理成五個階段（Vandergrift & Tafaghodtari, 2010; Vandergrift & Goh, 2012）：

| 階段 | 完整課堂版本的做法 | 主要後設認知工作 |
|---|---|---|
| 規劃／預測 | 教師提供主題與文本類型；學習者預測可能出現的資訊與詞語 | 規劃、定向注意（directed attention） |
| 第一次驗證 | 第一次聆聽後，學習者核對預測、記下新理解與未解處，再與同儕比較；雙方決定第二次要特別注意什麼 | 監控、評估、重新規劃、選擇性注意（selective attention） |
| 第二次驗證與重建 | 第二次聆聽用來處理先前分歧、修正錯誤並補充細節；之後由同儕或全班共同重建主旨與關鍵資訊，教師引導說明如何取得理解 | 監控、評估、問題解決 |
| 最後驗證 | 再聽一次確認仍未解決之處；後來整理的完整版本可依目的決定是否搭配逐字稿 | 選擇性注意、監控、問題解決 |
| 反思與目標設定 | 學習者評估哪些線索或策略有用、哪裡仍失敗，並決定下一次聆聽要調整什麼 | 評估、後續規劃 |

Vandergrift and Tafaghodtari（2010）的介入跨一學期進行。實驗組與控制組由同一教師授課、使用相同音檔並聆聽相同次數，但只有實驗組接受上述歷程引導；因此，研究比較的不是「有沒有多聽」，而是聆聽時是否系統性地預測、監控、驗證、解決問題與反思。

本文件以下提供的是<strong>低負擔個人版本</strong>：保留規劃、初聽、驗證、定位、最後重聽與反思的功能，但不要求每次都有教師、同儕與全班討論；並另外加入能力瓶頸路由、持續時間／篇章／聲學條件比較，以及未見材料評量。若在課堂或有同伴的環境使用，可以恢復同儕比較與教師引導；若獨立使用，則以可靠答案、局部逐字稿及明確紀錄承接部分核對功能。這些調整使方法較容易自行開始，也使它和原研究的完整介入不完全相同；詳細證據距離見第 8 節。

### 1.3 既有的最低負擔基準

在增加完整循環前，先保留更簡單的基準做法：選一段難度與目標相符的未見音檔，在目標允許的字幕、重播與時間條件下聆聽，回答少量內容問題或簡短重述，再核對可靠答案。若學習者已能在未見材料中達到目標，錯誤不反覆、重播負擔可接受，也知道何時需要查核，就維持這個簡單版本，不必每段都做完整錯誤分析。

這個基準可以檢查「是否理解」，卻不一定能回答「哪一層失敗」或「下一步應練什麼」。只有觀察到下列缺口時，才值得升級成策略循環：

- 答錯後只知道總分下降，不知道漏在聲音、詞義、句法、篇章、語用或監控哪一層。
- 反覆從頭重播，卻沒有縮小問題範圍，時間增加但未見材料沒有改善。
- 一看到完整字幕便覺得「懂了」，撤除字幕後仍無法從聲音重建內容。
- 短句或片段能懂，持續聽、進入篇章、限制重播或改變聲學條件後便失去主線。
- 這次靠背景知識猜對，卻無法指出答案依據，也不知道哪些部分其實仍不確定。

### 1.4 什麼不算本方法

以下活動可能有其他用途，但不構成本文件所說的完整循環：

- 只列出「預測、抓關鍵字、推論」等策略名稱，卻沒有實際聆聽、作答、核對與再評量。
- 每次一開始就看完整字幕或翻譯，使學習者不必先從聲音建構理解。
- 沒有指定目的地重播同一音檔，直到記住內容或答案。
- 把所有錯誤都解釋成「策略不夠好」，不檢查語音、詞彙、句法、篇章與語用知識。
- 只要求寫反思日誌，卻不檢查未見聽力表現是否改變。
- 用同一段材料撤除字幕後聽懂，就宣稱已能理解新節目、不同說話者或更長篇章。

### 1.5 和針對性語音辨識練習的分工

兩種方法可以前後銜接，但不能合併成一個模糊的「聽力練習」：

| 問題 | 先用哪個方法 | 理由 |
|---|---|---|
| 已知某個詞或語音形式，卻在聲音中反覆辨認錯誤 | 針對性語音辨識練習 | 可把 `PH-R` 缺口隔離成明確作答與回饋 |
| 能聽到多數形式，卻不確定錯在詞義、句法、篇章、語用或監控 | 聽力策略循環 | 需要在完整意義處理中定位並選擇後續處置 |
| 短例穩定，但連續篇章或限制重播後失敗 | 先用本循環分開條件 | 不能直接假定仍是局部語音問題 |
| 完整聆聽定位出一個可重複的語音瓶頸 | 轉入語音辨識練習 | 策略提醒不能取代聲音—形式連結的學習 |

## 2. 開始前先寫清楚目標與要求剖面

### 2.1 不用「提升聽力」當成目標

至少要寫成一項可觀察的任務，例如：

- 在檢定聽解的允許播放次數內，判斷對話中的決定與理由；
- 不看翻譯字幕，跟上指定類型 Podcast 的主線與關鍵細節；
- 在影劇對話中辨認人物立場、關係變化與重要語氣；
- 聽完一段課堂說明後，重述步驟、限制與前後因果。

### 2.2 寫出五項要求

| 向度 | 要回答的問題 |
|---|---|
| 精確度 | 只需主旨，還是人物、數字、否定、原因、語氣與笑點也必須正確？ |
| 速度 | 可暫停多久？必須跟上直播、正式播放或考試作答時限嗎？ |
| 提示條件 | 可否看題目、圖片、母語說明、字幕或逐字稿？可重播幾次？ |
| 語境範圍 | 哪些媒體、題材、說話者、口音、篇章長度與聲學環境屬於目標？ |
| 穩定性 | 需跨未見內容、不同集數、不同日期或不同說話者維持到什麼程度？ |

`A-EX-02` 應對齊正式題型、播放次數、口音、語速與作答時限；`D-LS-01` 則要指定媒體類型、可否回放、可容忍哪些背景細節，以及是否需跨集數持續理解。沒有可靠依據時不自行設定通用正確率、分鐘數或噪音門檻。

## 3. 材料與準備

### 3.1 材料要接近目標，但不以「面向母語者的內容」當品質保證

優先選擇與目標媒體、題材、說話者範圍、語速、篇章結構及聲學條件相近的材料。面向母語者的真實節目可以提供自然變異，卻可能同時加入大量陌生詞、背景知識、多人重疊、音樂與剪輯；若一次改變太多條件，就難以定位失敗。分級、教師製作或考試材料若較能控制難度，也可以作為前段基準，之後再回到目標來源驗證。

至少準備：

1. 一段未練過、可合法使用或聆聽的音檔。
2. 一到數個對齊目標的內容問題，或明確的重述要求。
3. 可核對的答案；需要定位時再準備可靠逐字稿、字幕或局部文字。
4. 一段不重複內容的未見音檔，用於遷移檢查。
5. 只有目標需要時，才另外準備不同篇章長度、說話者或聲學條件的比較材料。

### 3.2 逐字稿、字幕與重播是受控輔助

完整字幕會提供拼字、詞界與標點，把純聽力改成多模態理解。它可以在答後定位問題，卻不能和無字幕初聽混成同一個成績。優先只顯示造成困難的局部片段；學習者核對後，再撤除文字回到聲音。

重播次數同樣要記錄。若目標考試只播放一次，練習時可用額外重播定位與修正，但最後仍須回到一次播放的未見材料；若目標是可自由重播的 Podcast，則可把「用較少且更有目的的重播取得同等理解」列為成效之一。

## 4. 最低可行流程

### 4.1 第一次循環

1. **記錄目標條件**：寫下這次要理解什麼、可否重播、可用哪些提示，以及哪些資訊錯了會影響任務。
2. **有限預測**：只根據標題、畫面或真實情境可得線索，預測主題、可能人物與資訊結構；同時保留「預測可能錯」的選項，不先顯示完整詞表或逐字稿。
3. **無額外輔助初聽**：依目標播放規則聆聽，回答內容問題或重述。若目標原本提供題目或畫面，可照常保留。
4. **標記依據與不確定處**：不只寫答案，也標出是聽到明確詞句、由上下文推論，還是猜測；指出最早失去主線或信心下降的位置。
5. **必要時再聽一次**：只有目標或本次診斷允許時，帶著具體問題重聽，例如「代名詞指誰」或「原因從哪一句開始」，而不是無目的地從頭循環播放。
6. **用最少輔助核對**：先看答案或重聽局部；仍無法定位時，再看局部逐字稿、字幕、詞義或句法說明。一次只增加足以回答當前問題的提示。
7. **定位主要失敗層次**：依第 5 節判斷主要是聲音可用性、`PH-R`、`LX-R`、`GR-R`、`DC-R`、`PR-R`、`ST-MON`，或條件穩健性問題。一次錯誤可暫記「不確定」，不強迫單因歸類。
8. **撤除輔助再聽**：拿掉逐字稿、翻譯或答案，再聽原片段，說明現在能從哪些聲音、詞句或篇章線索重建理解。
9. **決定下一步**：若只是一次性疏漏便繼續新材料；若同類問題反覆出現，轉入對應的單項能力練習；若只在較長、較久或較吵條件出現，依第 6 節分開比較。

### 4.2 同一音檔與新音檔回答不同問題

同一音檔的最後重聽回答的是：「學習者在得到回饋後，能否重建這次內容與線索？」它是修正是否完成的過程證據。新音檔回答的才是：「這項監控或修正能否用到未見內容？」因此：

- 同一音檔進步可以支持已理解回饋，不能單獨支持泛化。
- 同一主題的新音檔可檢查內容變更後是否轉移，但仍可能受熟悉背景協助。
- 不同說話者、篇章或聲學條件只有在目標需要時才加入，且應註明究竟換了哪一項。
- 延遲後再用未見材料，可進一步檢查保持；不能以當場記住答案代替。

### 4.3 不是每次都做完整書面分析

剛開始可以用簡短表格記錄「答案—信心—依據—失敗層次—下一步」。當學習者已能穩定在聆聽中監控與選擇查核方式，就應逐步撤除表格與教師提示，回到較自然的意義導向聆聽。反思工具若長期比聆聽本身更耗時，而未改善未見表現，就失去低負擔基準的角色。

## 5. 錯誤定位與轉向路由

| 觀察到的現象 | 先檢查的層次 | 下一步 |
|---|---|---|
| 母語與目標語在同一設備或環境都聽不清 | 聲音可用性、設備、環境或一般聽覺因素 | 先修正播放條件；若困難長期跨語言與情境影響日常功能，本方法不能取代專業評估 |
| 看文字後知道詞與意思，撤掉文字卻聽不出音、詞界或重音 | `PH-R` 或聲音形式的 `LX-R` | 轉入[針對性語音辨識練習](./針對性語音辨識練習與立即核對.md) |
| 聽到或能寫下形式，卻不知詞義或當下義項 | `LX-R` | 補足目標詞義、搭配或多詞單位，再回完整音檔檢查 |
| 個別詞大多懂，卻誤判否定、時間、修飾、指涉或關係 | `GR-R` | 針對反覆結構做說明、對比與理解練習；不能只提醒「抓關鍵字」 |
| 單句懂，跨句後失去人物、因果、立場或主線 | `DC-R` | 練習指涉追蹤、命題整理與篇章關係；依第 6 節比較分段與連續篇章 |
| 字面內容清楚，卻誤判語氣、關係、諷刺或話外之意 | `PR-R` | 轉入有情境與對比的語用接收練習；語調只處理其中部分線索 |
| 答案有時對，卻不知道依據、過度自信或不知何時查核 | `ST-MON` | 維持本循環，練習標記信心、證據與最少必要查核 |
| 乾淨短句穩定，聽久、進入篇章、換人或加噪音才下降 | 條件穩健性與多能力整合 | 一次只改一項條件，依第 6 節定位；不要直接歸因於注意力或語音 |

真實聆聽中的各層會互相影響。表格用來縮小下一個可檢查問題，不表示大腦嚴格逐層運作，也不表示每次錯誤只有一個原因。

## 6. 從短片段接回真實情境

### 6.1 分開總聆聽時間、篇章整合與聲學條件

若短材料穩定、目標情境仍失敗，最低限度可比較：

| 條件 | 主要增加的要求 | 可幫助回答的問題 |
|---|---|---|
| 單一短句基準 | 局部語音、詞形與單句意思 | 最有利條件下是否已能處理局部內容？ |
| 獨立短句持續條件 | 總聆聽時間，但不需保留同一篇脈絡 | 表現是否只因聽久而在後段下降？ |
| 分段篇章條件 | 跨句保持與整合，段間可整理 | 給短暫停頓後能否維持主線？ |
| 連續篇章條件 | 持續聆聽、前文保持、整合與漏聽後恢復 | 不停頓時從哪裡開始失去內容？ |

四種條件若要比較，總播放時間、說話者、語速、詞彙、句法、主題及資訊密度應盡量相近。聲學條件另作一個可交叉的變項：先在乾淨錄音比較，再依目標加入噪音、混響或輕微失真。不能一開始同時加長篇章、換說話者、加噪音又限制重播，否則即使失敗也無法知道要改什麼。

### 6.2 比較前段、中段與後段

總分可能掩蓋處理成本。依任務需要分開記錄：

- 局部詞形辨認或聽寫；
- 單句意思與跨句內容問題；
- 聽後重述或延遲記憶；
- 前段、中段與後段表現；
- 主觀費力程度；
- 重播次數、位置與每次重播是否解決了明確問題。

正確率相同而主觀費力或聽後記憶惡化，仍表示任務成本改變（Peelle, 2018; Borghini & Hazan, 2018）。這些指標只用來定位與比較，沒有適用所有人的單一分數門檻。

### 6.3 不把任務內波動當成臨床診斷

後段退步可能來自尚未自動化的語音與詞彙處理、篇章整合、材料陌生、睡眠、焦慮、動機、設備或聽太久。若母語與目標語、聽講與閱讀及多個生活情境都長期出現相似困難並影響功能，才適合把完整情況交由合格專業人員評估。本循環不能篩檢或診斷注意力不足過動症、聽覺或其他臨床狀況。

## 7. 成效評量

### 7.1 至少分開五種結果

| 結果 | 最低評量方式 | 不能直接推出的結論 |
|---|---|---|
| 同一材料修正 | 撤除輔助後重聽並指出原先漏掉的線索 | 不能證明已能處理新材料 |
| 未見內容遷移 | 相近目標條件下的新音檔或新篇章 | 不能自動代表跨口音、跨媒體或跨難度 |
| 監控校準 | 比較作答信心、實際正確與是否能指出依據 | 自信下降不一定是退步，可能是更能察覺不確定 |
| 查核效率 | 記錄重播、字幕、逐字稿或查詞的次數、位置與是否解決問題 | 少用工具不必然較好；關鍵是符合目標且不犧牲必要精確度 |
| 條件穩健性 | 依目標分開改變持續時間、篇章、說話者、聲學條件或重播限制 | 一項條件成功不能替代其他條件 |

### 7.2 主要成效應回到目標任務

`A-EX-02` 至少要用未見正式題型，在規定播放次數與時限內看正確率、未作答率、每題時間及不同題型穩定性。`D-LS-01` 則可看主線與關鍵語氣理解、回看率、理解延遲、跨集數穩定性及指定語用推論。策略清單勾選數、反思字數或同一音檔的最後一次正確率只能作過程資料，不能替代這些結果。

### 7.3 劑量不預設固定處方

研究中的策略教學常跨多次課程，不能由此推出每位學習者都需要相同週數或每段固定重聽次數。現有統合結果也沒有形成一致的最低門檻：Chang（2024）整合一般聽力教學研究後，發現介入期間較長通常伴隨較大效果；Dalman and Plonsky（2025）整合聽力策略教學時，納入研究約跨一至二十四週，期間與效果量反而只有很小的負相關；Shintani and Wallace（2014）把聽力支援研究依總介入時間分組，也未發現短、中、長組間有顯著差異。這些研究的學習者、方法、測驗與時數往往同時不同，因此正反方向都不能當成單純的因果劑量—反應關係。

目前能較有把握地說的是：一般聽力教學及聽力策略教學平均上可能改善受測聽力結果，較長時間有時提供更多累積學習機會；但尚不能指定跨程度、語言配對與目標共用的「每週至少幾小時」。一至二十四週是研究介入的日曆範圍，不代表每週實際練習相同；少於某個總時數也不等於無效。一般第二語言排程研究同樣指出，分散方式的效果會隨內容、技能與預定保持時間改變，而每週只有一至二小時、課外接觸又很少的長期滴灌式課程，尤其不足以據此期待高階整體溝通能力；這是課程層級的間接證據，不是聽力進步的零效果線（Serrano, 2022）。

本方法因此先依[練習方法與證據框架](../練習方法與證據框架.md)第 7.4 節，記錄每次主動練習分鐘、每週次數與間隔、累積時間、日曆期間、課外接觸、材料準備與評量成本；另記音檔長度、循環次數、未見材料表現與操作負擔，再依結果決定是否維持。沒有可靠依據時，不自行設定「做滿幾次便學會」或「每週低於幾小時便不會進步」的數字。

### 8.3 合理推論、專案假說與未解問題

- **合理推論**：同一音檔用於定位與修正，未見音檔用於遷移評量，比只看最後一次重聽更能避免把記住答案誤當成學會。
- **合理推論**：只顯示必要的局部逐字稿，再撤除文字回到聲音，比全程顯示字幕更能保留「從聲音理解」的檢查條件；但最佳顯示量尚無通用答案。
- **專案操作假說**：用「失敗層次—下一步方法」路由，可能比每次從頭重播或泛用策略清單更省總時間；目前缺少直接比較。
- **專案操作假說**：先分開總聆聽時間、篇章整合與聲學條件，再決定加強哪一項，可能降低誤診與無效練習；這是由測量邏輯與相鄰研究支持的設計，尚不是已驗證的完整教學處方。
- **尚有爭議或資料不足**：哪些學習者受益最多、策略教學應持續多久、應教固定策略清單或依任務選擇、效果能否長期跨媒體與真實情境維持。
- **證據不足**：不同程度與目標是否存在可重複的每週最低時數，以及累積主動練習、日曆期間與課外接觸各自如何影響未見材料和目標任務表現。

## 9. 操作負擔、常見失敗與調整

### 9.1 應記錄的成本

| 成本 | 包含什麼 | 可觀察紀錄 |
|---|---|---|
| 材料準備 | 找音檔、答案、逐字稿與未見評量材料 | 準備分鐘、來源、逐字稿需人工修正處 |
| 初聽與作答 | 依目標條件完成內容理解 | 音檔長度、播放次數、作答時間 |
| 定位與核對 | 找不確定處、查看局部提示、分類錯誤 | 額外分鐘、使用哪些提示、是否能確定主要層次 |
| 再聽與轉練 | 撤除提示重建，或轉入單項能力練習 | 重播次數、轉練內容與回到完整聆聽的時間 |
| 評量 | 準備並完成未見、延遲與條件變化測量 | 評量時間、材料是否與練習重複 |

### 9.2 常見失敗模式

| 觀察到的問題 | 先檢查 | 低負擔調整 |
|---|---|---|
| 預測後只聽自己預期的內容 | 是否把預測當答案 | 要求列出替代可能，核對時指出推翻預測的聲音或語境線索 |
| 每段都從頭反覆播放 | 每次重播是否有具體問題 | 先標位置與問題，只重聽必要片段；目標不允許重播時另做一次播放的未見評量 |
| 看完完整字幕便以為已學會 | 是否撤除文字回到聲音 | 改用局部文字，核對後立即撤除，再以新音檔檢查 |
| 錯誤分類表填得很完整，未見理解沒改善 | 是否把反思本身當成果 | 縮短紀錄，只保留會改變下一步的方法；回到未見任務指標 |
| 所有錯誤都標成「專心不足」 | 是否先查語音、詞彙、句法、篇章與聲學條件 | 用第 5、6 節拆條件，不由一次波動推論臨床原因 |
| 所有錯誤都繼續做策略循環 | 是否已有反覆且可隔離的能力缺口 | 轉入對應能力練習，之後再回完整音檔驗證 |
| 材料太難，幾乎整段都無法定位 | 是否同時有大量未知詞、背景知識與不利聲學條件 | 降低一項難度或縮短片段，保留與目標相同的核心要求，再逐步接回 |
| 準備逐字稿與題目比練習耗時許多 | 是否已有成熟教材或可靠字幕 | 優先使用現成可核對材料；不為每段製作完整標註 |

## 10. 維持、升級與停止／轉向條件

### 維持目前方法

若未見音檔的理解與監控校準持續改善，能用較少或更有目的的查核完成目標，操作負擔可接受，而且錯誤路由確實導向不同處置，就維持簡單循環，不增加更多表格、策略名稱或科技。

### 局部升級

- 同一音檔會、未見內容不會：降低同題重複，改用同程序的新內容。
- 短句穩定、長時間獨立短句下降：先查局部處理是否仍太費力，再比較前、中、後段及主觀費力。
- 短句持續條件穩定、篇章下降：加入指涉、因果與主線追蹤；比較分段與連續篇章。
- 乾淨錄音穩定、目標聲學條件下降：一次加入一項噪音、混響或設備條件，保留乾淨基準。
- 固定說話者穩定、換人下降且目標需要跨人理解：逐步加入目標範圍內的新說話者。
- 有逐字稿才懂：減少顯示範圍，先核對局部，再撤除文字重聽。
- 能定位錯誤但無法修正：轉入相應的語音、詞彙、句法、篇章或語用方法，再回完整聆聽驗證。

### 停止完整循環或換方法

- 簡單的未見聆聽與答後核對已足以達成目標，完整分析只增加負擔。
- 主要瓶頸已穩定定位為一項語音、詞彙、句法、篇章或語用能力；應把主要時間轉到該能力，循環只保留為回測。
- 同一音檔持續進步，未見材料多次沒有改善；停止把重播熟練當成策略轉移。
- 逐字稿、答案或音訊品質無法可靠查核；停止用該材料診斷。
- 目標任務允許字幕、翻譯或轉錄直接完成，而且學習者沒有制度性、備援性或目標定義性的自行聽解需求；依 Q1／Q2／Q3 判斷優先直接使用工具。
- 困難長期跨母語與目標語、多種感官或生活情境出現並造成實際功能損害；本方法不承擔臨床解釋，轉由合格專業人員評估。

## 11. 最小示例：Podcast 短段聽到單句，卻接不起人物立場

假設一名中文母語的英語學習者能在短句中辨認多數詞，目標是不看翻譯字幕跟上訪談型 Podcast。初聽一段兩分鐘訪談後，學習者知道主題，卻把來賓轉述別人的反對意見誤當成來賓自己的立場。

1. **寫出目標**：能在來源原速、可回放一次的條件下，指出主持人與來賓各自主張及主要理由。
2. **有限預測**：根據標題預測可能爭點，但列出至少兩種可能立場，不先看詞表。
3. **初聽作答**：寫下兩人的立場、依據與信心，標出第一次失去人物對應的位置。
4. **帶問題重聽**：只針對「這句是誰的觀點」再聽一次，檢查代名詞、引述動詞與語調線索。
5. **局部核對**：仍不確定時，只看該兩句逐字稿。若詞都知道而錯在引述範圍與跨句指涉，主要記為 `GR-R`＋`DC-R`，不是繼續增加最小對立體辨音。
6. **撤除文字再聽**：拿掉逐字稿，口頭說明哪個語言線索標示「來賓正在轉述他人」。
7. **未見評量**：換另一段同類訪談，檢查能否在相同播放規則下追蹤立場。若新材料仍反覆誤判，轉做引述、指涉與篇章立場追蹤練習，再回 Podcast 驗證。

同一段最後聽懂只表示本次修正完成；未見訪談中的人物立場判斷改善，才較接近目標遷移。

## 12. 尚未解決的問題

本版仍不能提供下列普遍答案：

- 哪些學習者只需簡短答後核對，哪些需要完整後設認知循環；
- 預測、同儕比較、教師引導、局部逐字稿與反思各自的必要性及最佳組合；
- 每次循環的最佳音檔長度、重播次數、提示量與總週數；
- 對特定程度與目標，累積主動練習、每週頻率、日曆期間及背景接觸各自與進步的關係；
- 不同程度、年齡、語言配對、考試與興趣媒體如何調節效果；
- 策略改善能在多大程度上跨說話者、口音、篇章、媒體與長期真實情境維持；
- 哪些低負擔指標最能區分理解改善、監控校準、聆聽努力降低與單純熟悉材料；
- 本文件的錯誤路由是否比一般答後訂正、教師講解或自由重播節省達標總時間；
- AI 轉錄、錯誤診斷或自動出題在指定語言、口音、篇章與噪音條件下是否可靠，以及是否能改善學習而不只是減少準備時間。

遇到這些問題時，應把方法選擇寫成可修改的操作假說，記錄材料、提示、總時間、未見表現與失敗案例；不能把軟體的信心分數、字幕品質或策略建議直接當成學習者的聽力能力。
